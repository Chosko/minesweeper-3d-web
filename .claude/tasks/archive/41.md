## Goal
Build the Settings page of feature `settings`, reached from the main menu:
sections for controls, graphics, theme and audio, each control bound to one
schema entry and built from the screen kit, a read-only bindings list drawn
from the same source as the in-game help, and the pause card's quick access
to sensitivity, invert Y and volume bound to the same store.

## Acceptance criteria
- The main menu's Settings entry routes to the page (replacing its
  placeholder); Back returns to the screen it was opened from.
- Controls (sensitivity slider, invert Y toggle), graphics (fullscreen
  toggle, resolution segmented choice), theme (Light / Dark segmented
  choice) and audio (volume slider, mute toggle) are generated from the
  schema; each change applies at once.
- The bindings list shows each mode's bindings per input device from one
  bindings source that the in-game help also reads.
- The pause card's sensitivity, invert Y and volume controls read and write
  the store.
- Fully operable by mouse, keyboard and controller with a declared default
  focus.
- Playwright checks: open Settings from the menu, switch to Dark, reload,
  and Dark is still applied before the menu shows.
