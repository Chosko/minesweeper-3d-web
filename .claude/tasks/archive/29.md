## Goal
Build the board vocabulary of feature `game-summary`: the board identity
(mode, grid, width, height, mine count, no-guess), its canonical string key
that records are indexed by, and its display label, with Beginner,
Intermediate and Expert recognised from their exact dimensions and mines.

## Acceptance criteria
- A DOM-free module builds a board identity from its fields and validates
  them (a range error for impossible values).
- `boardKey(identity)` gives the same key for the same fields in every build;
  the key format is documented in the module as part of the stored records,
  changing only with a records format version.
- `boardLabel(identity)` gives "Expert", "Expert · no-guess",
  "20 × 12 · 50 mines" and the like; a custom board matching a standard size
  and mine count is labelled and keyed as that standard board.
- Node tests pin keys and labels for the three standard boards with and
  without no-guess and for custom boards.
