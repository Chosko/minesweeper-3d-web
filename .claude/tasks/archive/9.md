## Goal
Build the deterministic base of feature `board-generation`: a fixed seeded
pseudo-random source owned by the generator, and the placer that draws a
uniformly random mine set over any cell graph honouring the reference
ruleset's first-click guarantee — the first-click cell is safe, not
necessarily an opening. The generator version is defined here and recorded
with each board.

## Acceptance criteria
- A fixed pseudo-random algorithm seeded from a 32-bit (or wider) seed,
  independent of `Math.random` and the platform; a test pins its first
  outputs for a known seed.
- The placer takes a cell graph, a mine count, a first-click cell and a
  seeded source, and returns a mine set as cell indices. Only the first-click
  cell is excluded; its neighbours may hold mines, as the reference does
  (`tests/fidelity/minesweeper-online.md`, first-click guarantee).
- An impossible request (more mines than every cell but the first-click
  cell) is rejected at once with a reason.
- Determinism: same request and generator version → same mine set; a test
  pins one Expert board's mine set for a fixed seed.
- A distribution test over many seeds shows every cell but the first-click
  cell can hold a mine — its neighbours included — and the first-click cell
  never does.
- A `GENERATOR_VERSION` constant is exported; changing the source or the
  placer's draw order requires bumping it (stated in the module header).
