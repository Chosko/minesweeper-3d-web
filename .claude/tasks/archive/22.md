# Task 22 — Tile painter, tile cache and minimum tile size

Archived: 2026-10-10
Status: [DONE]

Feature: square-tile-skin

Target: claude

## Goal
Build the drawing side of feature `square-tile-skin`: a stateless tile
painter the Classic 2D renderer calls per tile, a cache that pre-renders each
state and number at the current tile size and pixel ratio, the theme-change
hook that drops the cache and asks for a redraw, and the shared minimum tile
size constant, fixed by measurement.

## Acceptance criteria
- `paintTile(ctx, x, y, size, state, number)` paints one tile in any of the
  visual states the rules engine reports (closed, pressed, revealed empty,
  revealed number, flagged, mine, exploded mine, wrong flag), using tile
  tokens read through the token reader; an unknown state paints a visibly
  wrong placeholder.
- Tiles are drawn plainly — a flat fill, a simple edge and a plain glyph per
  state, with no bevel, shading or texture work beyond that; closed and
  revealed tiles still differ by more than colour alone (the simple edge),
  in both themes.
- The tile cache pre-renders every state and number to offscreen images keyed
  by tile size, device pixel ratio and theme, and is invalidated on any of
  the three changing; a full redraw is a sequence of image copies.
- The skin subscribes to `onThemeChange`, drops its cache and calls a
  redraw callback its renderer supplies.
- `MIN_TILE_SIZE` is exported as a shared constant, set from the tile size an
  Expert board gets in a 1366×768 window and in a 1280×800 (Steam Deck)
  window, with Playwright screenshots at that size in both themes showing
  every state and number legible.
- `.claude/domain/features/square-tile-skin.md` records the measured minimum
  size as settled in place of its open question. Nothing else in the
  document changes.
- Node tests cover state dispatch, the placeholder and cache keying with a
  fake canvas context.

## Decisions
- Low-fidelity pass: the painter draws every state legibly with plain
  shapes; the high-fidelity tile look comes from the approved designs in a
  later pass, and those designs are not an input to this task.
- Settled here: the feature document's open question on the smallest
  legible tile size, by the measurement it names, with a 1280×800 window
  standing in for the Steam Deck screen.
  `.claude/domain/features/square-tile-skin.md` is normally `/architect`'s;
  this task updates it for exactly this and for nothing else.
