## Goal
Add the summary record of feature `game-summary`: a builder that turns the
engine's game summary (or its counts for an abandoned game), the elapsed
time, the board choice, the seed and generator version into one summary
record, with 3BV/s and efficiency derived by one shared rule and the rule
for which games are eligible for a personal best.

## Acceptance criteria
- `buildSummary(...)` returns a plain, serialisable record: id, board
  identity, outcome (won, lost, abandoned), elapsed time (ms), 3BV, 3BV
  solved, click counts by kind, 3BV/s, efficiency, seed, generator version,
  end date.
- Invalid input (negative time, counts that do not fit the board) throws a
  range error.
- 3BV/s = 3BV solved ÷ elapsed seconds; efficiency = 3BV solved ÷ counted
  clicks as a percentage, where counted clicks are the engine's count under
  its pinned reference rule; a zero divisor gives "not available", never 0
  or infinity. Each derivation is an exported pure function of the record's
  own fields.
- A game abandoned after its first click is summarised as abandoned; a game
  left before its first click produces no summary.
- `isBestEligible(summary, stat)` is true only for won games with that stat
  available.
- Node tests cover won, lost and abandoned summaries, the zero-divisor
  cases, eligibility and invalid input.
