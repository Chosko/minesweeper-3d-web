## Goal
Put feature `classic-2d-square-play` behind the game shell: the board choice
screen (Beginner, Intermediate, Expert, Custom, no-guess switch), the mode
contract implementation, the overlay feed of timer and mines left, and the
pause / restart / back-to-menu behaviour the shell asks for, so Classic 2D is
playable from the main menu.

## Acceptance criteria
- The main menu's Classic 2D entry opens a board choice screen built from kit
  components, preselected from the last board choice; Custom shows width,
  height and mines inputs validated against `CUSTOM_LIMITS`.
- A Classic 2D mode registered with the mode host implements open board
  choice, start, pause, resume, restart, leave and `summary()`, and reports
  started, finished, abandoned and can-pause.
- `summary()` returns a started, unfinished game's summary so far, outcome
  abandoned, built the same way as the abandoned report's; before the first
  click it returns nothing. Node tests cover it before the first click and
  mid-game.
- Timer and mines left are pushed to the overlay bar whenever they change.
- Pause freezes the timer and hides the board, and does nothing to the timer
  before the first click or after the game ends; restart and leave release
  the canvas and any pending generation.
- A finished game routes to the results route with its summary; *Play again*
  starts a new game with the same choice.
- A Playwright check goes menu → Classic 2D → Expert → first click → pause →
  resume → back to menu (confirming the loss) and checks the abandoned
  summary was emitted.
