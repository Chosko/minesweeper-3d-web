# Task 105 — Watch replay from a leaderboard entry

Target: claude

## Goal
Complete feature `leaderboard-screen`: *Watch replay* on an entry asks
`steam-leaderboards` for the replay and opens it in `replay-playback`'s
viewer, with Back returning to where the rankings showed — the leaderboard
screen, or the Records screen on its Leaderboards tab — on the same board,
scope and position.

## Acceptance criteria
- *Watch replay* calls `replayFor(entry)`; on success it routes to the
  replay viewer (2D or 3D by the replay's mode) with the replay.
- *Watch replay* lives in the rankings part (task 104), so it works
  wherever the part is shown. Back from the viewer returns to the part's
  host — the leaderboard screen, or Records with its Leaderboards tab
  selected (task 107) — on the same board, scope, loaded pages and focused
  row.
- A failure is reported on the row with its reason (no replay, download
  failed, unreadable, does not match, or the viewer's own verification);
  the list stays usable.
- In the web build the button opens the library's replay of the player's
  own game.
- Node tests cover the success route, each failure reason and the restored
  position for both hosts with fakes; Playwright checks a local replay opens
  and returns.

## Decisions
- **Two hosts** (owner's answer: the Records Leaderboards tab shows the
  rankings in place): the return target is the host that showed the
  rankings, so the Records tab needs no replay wiring of its own.
