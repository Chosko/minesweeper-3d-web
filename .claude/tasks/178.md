# Task 178 — Live figures in the replay viewer

Target: claude

## Goal
Show the live figures of feature `in-game-layout` for the replayed game beside
the replay viewer's playback controls, in both modes, derived from the
replay's frame and the board's bests as they stand, as J-Replay-xl/-l/-m/-p
and J-Replay-states draw them.

## Acceptance criteria
- The figures panel is composed from the artboards using catalogued
  components only.
- The figures follow the playback position, including after a seek back or
  forward, from task 174's model fed with the frame's counts and the replay
  clock's elapsed time.
- Bests are those stored now, not at the time the game was played.
- Existing replay viewer tests pass; a test seeks a fixture replay and checks
  the figures at known frames.

## Decisions
- **Its artboards exist** — J-Replay-* on the canvas — so the manual
  intervention this task carried while the artboard was undrawn is gone and
  the task is `claude`.
