# Task 234 — Pause card to the canvas

Target: claude

## Goal
Bring the shared pause card in line with the *Joyful tiles* canvas
(Claude Design artifact https://claude.ai/artifact/LeP32jxNxEnHLUtRwJ3FNC,
page "Joyful tiles"). A design review found its title block, size, icons,
confirmation, settings rows and no-game state drift. Part of the canvas
drift fixes; intended feature: `shared-screen-layout`. Drift ids: F21,
F22, F23, F25, F26 (use of K16), F27.

## Acceptance criteria
- **Title block (F21).** "Paused" 34px heavy; board line in 15px bold with
  the full line — mode, board, size, mines and no-guess, for example
  "Classic 2D · Intermediate · 16 × 16 · 40 mines · no-guess"; status line
  JetBrains Mono 15px; gaps 6 and 4px.
- **Size (F25).** Card 920 wide at xl, padding 26px 28px (18px on the
  phone).
- **Icons (F22).** Resume a play icon, Restart a restart icon, Main menu an
  arrow-left icon.
- **Settings rows (F23).** Sound uses the switch row (label left, switch
  right); Volume label above one row with the track (teal-edge fill) and
  the value — task 219's parts.
- **Confirmation (F26).** Task 221's confirm box: "Leave this game?" /
  "This game will count as a loss." with a danger "Confirm" and Cancel,
  for both Restart and Main menu.
- **No game (F27).** With no game in progress (before the first click, or
  after the end) the status line reads "No game in progress: the board is
  not started yet." (the canvas's wording; an ended game uses the
  matching canvas line if drawn), Restart (with its F2 hint) is primary
  and first, Main menu follows, and there is no Resume.
- Pause tests updated; renders match the artboards at xl, l, m and p.
- `.claude/context/app-shell-pause.md` reflects the card.

## Decisions
- Canvas artboards to check against: J-Pause-xl, J-Pause-l, J-Pause-m,
  J-Pause-p, J-Pause-states ("Restart confirmation", "Main menu
  confirmation", "No game (before the first click / ended)").
- Owner decision 11 (F27): adopt the canvas no-game card (status line,
  Restart first, no Resume).
- The controls list inside the card is task 233's.
- Depends on tasks 221 (confirm box) and 233 (controls list).
