Target: claude

## Goal
Feature `game-shell` adds the screen router, shell navigation, the mode host
with its 3D adapter, the four-entry main menu and the shared pause flow. The
app-shell documentation still describes a single 3D-only mode state and
needs to reflect the shipped shell.

  `S.mode` relates to the router.
- `.claude/context/input.md` describes the shell navigation layer over the
  controller reader.
- `.claude/context/testing.md` lists the shell tests; `.claude/context/INDEX.md`
  covers the new files.
