# Task 181 — Board module shape, the Joyful tiles board module and the board conformance checks

Target: claude

## Goal
Define the theme board module of feature `themed-board-art-and-motion` —
palette, number colours 1–26 and number font, sky and fog, drawing style and
parameters, and a motion description per cell event — write *Joyful tiles*'
board module from the feature document, its artboards and the derivation
rules, and add the board conformance checks that the theme conformance suite
runs for every theme.

## Acceptance criteria
- `js/themes/board-module.js` documents the shape (every palette entry the
  feature document lists, `numbers[1..26]`, number font family and weight,
  `sky.{horizon,zenith,nadir,fog?}`, `style.{name,params}`,
  `motion.{press,release,reveal,flag,unflag,chordPress,solvedPulse}` each a
  description or `null`) and the motion vocabulary (scale, offset, rotation
  with flip, depth, brightness, opacity; a duration, an easing as a named
  curve or cubic Bézier, keyframed tracks), and exports the board conformance
  checks.
- **Board checks:** every palette entry present; 26 number colours; a shipped
  style with all its parameters; an entry for every cell event, each a
  vocabulary-only description with a positive duration or `null`; each number
  colour at least 4.5:1 against every point of the revealed face; closed and
  revealed faces distinguishable by more than colour; cursor ring and
  selection outline at least 3:1 against both faces; every state and number
  legible at `MIN_TILE_SIZE`.
- The theme conformance suite's to-do board case (task 161) is turned on and
  runs these checks for every registered theme.
- **Joyful tiles board module** `themes/joyful-tiles/board.js` replaces the
  placeholder: style flat with its parameters; the closed face a tint close
  to the game's current light closed tile, so the flag stays visible on it;
  the flag as the game draws it today in the light look; numbers 1–8 in the
  glyph style and colours the game draws today in the light look (weight,
  outline, shadow), set in one fixed self-hosted font rather than the system
  font stack; revealed and cursor colours from the S3D-Game artboard; mine,
  exploded mine, wrong-flag cross, pressed face, numbers 9–26 and the sky by
  the feature document's derivation rules (numbers 9–26 from the 3D mode's
  reference hues adjusted in lightness to pass contrast; the sky from the menu
  artboard's navy 3D panel); motion as the interim set: no press or chord
  press motion (the design proposes the flat press), a short scale-in on
  reveal and the reference solved pulse.
- **Number font.** *Joyful tiles*' numbers use one bundled, self-hosted font
  loaded like the theme's other fonts. Until the design names the font, the
  task bundles an interim one matching the current glyph style, marked in a
  comment as the design's to replace.
- **Flat faces pass the board checks unchanged** — *Joyful tiles*' closed and
  revealed faces differ by more than colour; the check is not relaxed for the
  flat style. How they differ comes from the design; until its components
  artboard shows it, the task takes the smallest difference that passes,
  marked in a comment as the design's to replace.
- Each derived value carries a comment naming the rule it came from.
- A test runs the checks against broken fixture board modules (a missing
  palette entry, a low-contrast number, an unknown style, a motion track
  outside the vocabulary) and asserts each is caught; *Joyful tiles* passes.

## Decisions
- **Owner's look for Joyful tiles** — flat tiles; the closed tint and the
  game's light-look numbers and flag, in one fixed self-hosted font, as the
  feature document states; where the S3D-Game artboard draws otherwise, the
  document wins.
- **Interim Joyful tiles values** for what its artboards leave undrawn, for
  its motion, its number font and its flat-face difference, per
  `themed-board-art-and-motion.md` § Open questions; the theme skill's update
  replaces them when the components artboard is drawn.
- **Settled design detail**
  (`.claude/domain/features/themed-board-art-and-motion.md` § Data and state,
  *Board module*, *Motion description*): the event key names and the module
  path. The feature document is not edited here; task 187 records what holds
  at ship time.
