# Task 181 — Board module shape, the Joyful tiles board module and the board conformance checks

Target: claude

## Goal
Define the theme board module of feature `themed-board-art-and-motion` —
palette, number colours 1–26 and number font, sky and fog, a drawing style
and its parameters per mode (Classic 2D tiles, 3D cubes), the 2D corner
radius and gap, and a motion description per cell event — write *Joyful
tiles*' board module from the canvas's J-BoardSheet and J-3DSheet, and add
the board conformance checks that the theme conformance suite runs for every
theme.

## Acceptance criteria
- `js/themes/board-module.js` documents the shape (every palette entry the
  feature document lists, `numbers[1..26]`, number font family and weight,
  `sky.{horizon,zenith,nadir,fog?}`, a style per mode — `style2d` and
  `style3d`, each `{name, params}`, the 2D one carrying the corner radius and
  the gap as fractions of the tile —, the cursor ring's colour and radius
  rule, the 3D selection — outline colour and width rule, the colour of the
  glow line inside it and the selected face's tint —, the 3D confetti
  colours, `motion.{press,release,reveal,flag,unflag,chordPress,solvedPulse}`
  each a description or `null`) and the motion vocabulary (scale, offset,
  rotation with flip, depth, brightness, opacity; a duration, an easing as a
  named curve or cubic Bézier, keyframed tracks), and exports the board
  conformance checks.
- **Board checks:** every palette entry present; 26 number colours; a
  shipped style with all its parameters for each mode; an entry for every
  cell event, each a vocabulary-only description with a positive duration or
  `null`; each number colour at least 4.5:1 against every point of the
  revealed face; closed and revealed faces distinguishable by more than
  colour in each mode; cursor ring and selection outline at least 3:1
  against both faces; every state and number legible at `MIN_TILE_SIZE`.
- The theme conformance suite's to-do board case (task 161) is turned on and
  runs these checks for every registered theme.
- **Joyful tiles board module** `themes/joyful-tiles/board.js` replaces the
  placeholder, every value from the canvas:
  - **2D** (J-BoardSheet): style flat — closed face with its light top band
    and dark bottom edge, revealed face flush with a hairline; corner radius
    15 % of the tile, the cursor ring's radius following it (tile × .15 +
    3 px), the board frame's tile × .3; the gap 9 % of the tile; every tile
    state at both drawn sizes, the cursor ring and the marked start cell.
  - **3D** (J-3DSheet, "Bevel 5 %"): style bevel — closed and flagged cubes
    with the thin dark edge and the four lit sides, revealed cubes flat cream
    inside their edge with no slope, the exploded mine's coral face and edge;
    numbers 1–26 with J-3DSheet's derived 3D colours; the sky, fog, ground
    grid, start-cell tint, view-mode alphas and waves unchanged from
    J-3DSheet; the selection outline `#16204a` at max(0.06 of the face,
    3 px), a 1 px `#ffc93c` glow line inside it, and the selected face's
    colour multiplied by (1, .86, .84) toward coral; the confetti colours
    coral `#ff6b6b`, yellow `#ffc93c`, teal `#49c6b8`, blue `#78aaf8`, violet
    `#6d4ee8`, white `#ffffff` and orange `#ff8c42`.
  - Numbers 1–8 and the flag in the game's glyph style (weight, outline,
    shadow) set in Rubik 800 from the theme's self-hosted fonts (task 157).
  - Motion from J-BoardSheet's cell-motion keyframes (press, release,
    reveal, flag, unflag, chord press) and J-3DSheet's solved pulse.
- Each value carries a comment naming the artboard it came from.
- A test runs the checks against broken fixture board modules (a missing
  palette entry, a low-contrast number, an unknown style, a missing 3D
  style, a motion track outside the vocabulary) and asserts each is caught;
  *Joyful tiles* passes.

## Decisions
- **Owner decisions** (DESIGN-CHANGES §3.3, §3.4): flat 2D tiles with a
  radius and gap that scale with the tile, and "Bevel 5 %" 3D cubes; the
  canvas holds every value. This replaces the interim values (derived
  numbers 9–26 and sky, an interim number font, the smallest flat-face
  difference, interim motion) this task first carried, and the single style
  per theme: the module now names one style per mode.
- **The 3D selection and the confetti are board-module values**: the
  renderer reads and tests them in task 213; this task writes them and
  their place in the shape.
- **The atlas is generated, not shipped** (DESIGN-CHANGES §5): the game
  draws its atlas from these values (task 183); the canvas PNG is the
  reference only.
- **Settled design detail**
  (`.claude/domain/features/themed-board-art-and-motion.md` § Data and state,
  *Board module*, *Motion description*): the event key names, the per-mode
  style keys and the module path. The feature document is not edited here;
  task 187 records what holds at ship time.
