# Task 90 — Update documentation for feature `steam-desktop-host`

Target: claude

## Goal
Feature `steam-desktop-host` adds the Electron host, the capability adapter,
the page bridge, platform selection with capability flags, and the Windows
and SteamPipe build. The navigation layer and README describe only the web
preview and need to describe the shipped desktop host.

## Acceptance criteria
- A new `.claude/context/desktop.md` describes the main process, the custom
  protocol, the adapter and its implementations, the bridge's requests,
  events and typed errors, the closing sequence, and the packaging and
  SteamPipe scripts.
- `.claude/context/platform.md` describes the start-up selection and the
  capability flags; `app-shell.md` names the overlay pause and the quit
  flush.
- `.claude/context/testing.md` lists the new tests and how desktop tests
  run; `.claude/context/INDEX.md` lists `desktop.md`.
- `README.md` explains how to run the desktop build locally and how a
  private Steam build is produced.
