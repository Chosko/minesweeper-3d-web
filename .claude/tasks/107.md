# Task 107 — Leaderboards and Quit entries in the main menu

Target: claude

## Goal
Implement feature `leaderboards-menu-entry`: unlock the Leaderboards entry and
the Quit control that the shared layout's main menu (task 165) shows locked.
Leaderboards, after Surface and before Daily, unlocks in both builds and opens
the leaderboard screen with no board; Quit, the final control after Settings
and set apart from the list, unlocks in the desktop build and asks the host to
run its closing sequence.

## Acceptance criteria
- Leaderboards is unlocked in the web and the desktop build, in the place task
  165 gives it; Quit is unlocked only when the desktop-host capability flag is
  on (whether or not Steam started) and stays locked otherwise. Default focus
  stays on the first entry.
- Both are mode entries — icon, label and an accent the kit catalogue declares
  for the mode entry — as the S3D-Menu artboard draws them, unlocking with no
  change to the menu's composition, no styling of their own and no rule added
  to any theme stylesheet; contrast checks pass under *Joyful tiles*.
- Leaderboards routes to the leaderboard screen with no board, pushing the
  menu on the back stack; Back returns to the menu with focus on
  Leaderboards. The entry is always unlocked, whatever Steam's state.
- Quit sends the bridge's quit request and disables itself while it is in
  flight, so a second activation sends nothing; a rejected request
  re-enables it. The page does no flushing of its own on Quit and asks no
  confirmation.
- Both entries are in focus order for mouse, keyboard and controller; Esc
  and the back button on the main menu never quit.
- Node tests cover menu composition both ways (Quit locked on the web,
  unlocked on the desktop), the quit flag and rejection with a fake bridge;
  Playwright checks the web menu and the Leaderboards round trip.

## Decisions
- **Shared layout:** the entries are the locked ones task 165 composes
  (`leaderboards-menu-entry.md` § Architecture, *Menu entries*), so this task
  waits on task 165. No detail line, as the shared layout's mode entry has
  none.
- **Quit on the web stays locked** — the owner's answer.
