# Task 107 — Leaderboards and Quit entries in the main menu

Target: claude

## Goal
Implement feature `leaderboards-menu-entry`: the main menu's column of mode
entries in the shared layout becomes Classic 2D, 3D, Records, Leaderboards,
Settings and, in the desktop build, Quit. Leaderboards opens the leaderboard
screen with no board; Quit asks the desktop host to run its closing
sequence.

## Acceptance criteria
- The menu's mode entries are Classic 2D, 3D, Records, Leaderboards,
  Settings, then Quit only when the desktop-host capability flag is on
  (whether or not Steam started); in the web build Quit is absent, not
  disabled. Default focus stays on the first entry.
- Leaderboards and Quit are each one mode entry — icon, label, detail line
  and an accent the kit catalogue declares for the mode entry — as the
  S3D-Menu artboard draws them, added to the open-ended column with no
  change to the menu's composition, no styling of their own and no rule
  added to any theme stylesheet; contrast checks pass under *Joyful tiles*.
- Leaderboards routes to the leaderboard screen with no board, pushing the
  menu on the back stack; Back returns to the menu with focus on
  Leaderboards. The entry is always shown, whatever Steam's state.
- Quit sends the bridge's quit request and disables itself while it is in
  flight, so a second activation sends nothing; a rejected request
  re-enables it. The page does no flushing of its own on Quit and asks no
  confirmation.
- Both entries are in focus order for mouse, keyboard and controller; Esc
  and the back button on the main menu never quit.
- Node tests cover menu composition both ways, the quit flag and rejection
  with a fake bridge; Playwright checks the web menu and the Leaderboards
  round trip.

## Decisions
- **Shared layout (2026-10-13):** the entries join the main menu task 165
  composes, as mode entries (`leaderboards-menu-entry.md` § Architecture,
  *Menu entries*), so this task waits on task 165. The S3D-Menu artboard
  already draws both entries; their icon and detail line come from it.
