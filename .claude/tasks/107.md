# Task 107 — Leaderboards and Quit entries in the main menu

Target: claude

## Goal
Implement feature `leaderboards-menu-entry`: the main menu becomes Classic
2D, 3D, Records, Leaderboards, Settings and, in the desktop build, Quit.
Leaderboards opens the leaderboard screen with no board; Quit asks the
desktop host to run its closing sequence.

## Acceptance criteria
- The menu lists Classic 2D, 3D, Records, Leaderboards, Settings, then Quit
  only when the desktop-host capability flag is on (whether or not Steam
  started); in the web build Quit is absent, not disabled. Default focus
  stays on the first entry.
- Leaderboards routes to the leaderboard screen with no board, pushing the
  menu on the back stack; Back returns to the menu with focus on
  Leaderboards. The entry is always shown, whatever Steam's state.
- Quit sends the bridge's quit request and disables itself while it is in
  flight, so a second activation sends nothing; a rejected request
  re-enables it. The page does no flushing of its own on Quit and asks no
  confirmation.
- Both entries are in focus order for mouse, keyboard and controller; Esc
  and the back button on the main menu never quit.
- Node tests cover menu composition both ways, the quit flag and rejection
  with a fake bridge; Playwright checks the web menu and the Leaderboards
  round trip.
