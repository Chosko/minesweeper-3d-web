# Task 107 — Leaderboards tab in Records and Quit in the main menu

Target: claude

## Goal
Implement feature `leaderboards-menu-entry`: make the Records screen's
Leaderboards tab — built with its coming-soon panel by task 170 — show the
rankings of the board Records shows, in place, inside Records, in both
builds; and make the main menu's Quit entry, which task 165 shows locked on
the web, work in the desktop build by asking the host to run its closing
sequence.

## Acceptance criteria
- **Leaderboards tab.** In the web and the desktop build the tab replaces
  its coming-soon panel with `leaderboard-screen`'s rankings part (task 104)
  for the board Records shows: scope tabs, own standing, entry list with
  *Watch replay*, and the loading, empty, offline, unavailable and
  local-only states. It follows Records' board and no-guess choice and
  reloads when either changes; it adds no board picker of its own and never
  routes to the leaderboard screen. A board with no leaderboard (a custom
  board, or any board outside `steam-leaderboards`' catalogue) shows one
  line saying it has no leaderboard. Back from a replay watched from the tab
  returns to Records with the tab selected, on the same board, scope and
  position (task 105). The tab is always shown, whatever Steam's state; Steam
  unavailable or offline is reported in the rankings, never by hiding the
  tab. No main-menu entry for Leaderboards.
- **Quit.** The menu's final entry is enabled only when the desktop-host
  capability flag is on (whether or not Steam started) and stays locked
  otherwise, as task 165 draws it, with no styling of its own and no rule
  added to any theme stylesheet. Quit sends the bridge's quit request and
  disables itself while it is in flight, so a second activation sends
  nothing; a rejected request re-enables it. The page does no flushing of
  its own on Quit and asks no confirmation.
- Both are in focus order for mouse, keyboard and controller; the tab's
  scope inputs work inside Records as on the leaderboard screen; Esc and the
  back button on the main menu never quit.
- Node tests cover the tab for a catalogue board and for a custom board, its
  reload on a board or no-guess change, Quit both ways (locked on the web,
  enabled on the desktop), the quit flag and rejection with a fake bridge;
  Playwright checks the Records tab's local-only rankings on the web build.

## Decisions
- **Owner decision** (DESIGN-CHANGES §2.2): Leaderboards leaves the main
  menu and becomes Records' fourth tab; this replaces the Leaderboards menu
  entry this task first carried.
- **Rankings in place** (owner's answer: "here in records"): the tab shows
  the selected board's rankings inside Records, with no link out to a
  separate leaderboard screen. This settles the open question that made
  this task wait on a manual decision, so it is `claude` and has no manual
  intervention.
- **Quit on the web stays locked** — the owner's answer.
