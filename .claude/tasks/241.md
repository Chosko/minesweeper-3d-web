# Task 241 — Other surfaces: placeholder, fatal card and toasts

Target: claude

## Goal
Bring the Coming-soon placeholder, the fatal card and the toasts in line
with the *Joyful tiles* canvas (Claude Design artifact
https://claude.ai/artifact/LeP32jxNxEnHLUtRwJ3FNC, page "Joyful tiles").
Part of the canvas drift fixes; feature: `shared-screen-layout`.
Drift ids: A1, A10, A13, A25, B32, F29, and the placeholder's back
buttons (A4, A9).

## Acceptance criteria
- **Placeholder badge (A1).** A 120×120 lock badge above "Coming soon":
  radius 30, --color-locked fill, `0 8px 0` --color-locked-edge drop, 56px
  lock icon; column gap 16.
- **Placeholder buttons (A4, A9).** The head's "Main menu" and the panel's
  "Back" start with the arrow-left icon; on the phone the head button
  reads "Back" with aria-label "Back to Main menu".
- **Placeholder position (A10).** Frame top at 256 (xl) and 120 (l, m), not
  4px lower from centring.
- **Fatal focus (A13).** The fatal card's Reload button is focused when the
  card appears (the `autofocus` attribute does nothing on a template clone
  appended after load, so focus it explicitly).
- **Card motion (A25).** Every card animates in and out over
  `--duration-slow` — the fatal card, the placeholder and the
  confirmation as well as ready, ctx-lost and learn-end (respecting
  reduced motion).
- **Toasts (B32, F29).** Max-width 640; centred at bottom 28px (the restart
  toast no longer sits about 60px up over the window foot).
- Tests for the placeholder, fatal path and toasts updated.
- `.claude/context/app-shell-ui.md` (or the context file that describes
  these surfaces) reflects them.
