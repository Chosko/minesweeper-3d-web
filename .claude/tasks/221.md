# Task 221 — Kit feedback parts: confirm box, warn and err notes

Target: claude

## Goal
The *Joyful tiles* canvas (Claude Design artifact
https://claude.ai/artifact/LeP32jxNxEnHLUtRwJ3FNC, page "Joyful tiles";
classes `j-confirm`, `j-warn`, `j-err`) draws a danger confirmation box and
filled warning and error lines; the kit has neither, so screens fall back
on a white `ui-panel` and plain warning text. Add the parts to the kit and
use them where the canvas draws them. Part of the canvas drift fixes;
intended feature: `shared-screen-layout`. Drift ids: K16 box and copy
(A14, A15, B27, F26, H1-45, H2-34), K15 (E12, E14, G12, H2-35).

## Acceptance criteria
- **Confirm box (K16).** A `ui-confirm` kit part: fill --color-danger-fill
  #ffe1de, radius 16, padding 16px 18px, gap 12, no border and no drop;
  text 17px/700 ink; an optional heading (24px) where the canvas draws one;
  actions side by side — the danger button (task 218's
  `ui-button--danger`) then Cancel (secondary md). It replaces the
  `ui-panel` used for:
  - the pause confirmation (`#pause-confirm`): heading "Leave this game?",
    text "This game will count as a loss.", danger button "Confirm", then
    Cancel — for both the Main menu and the Restart confirmation (shipped:
    no heading, "Leave this game for the main menu? It will count as a
    loss." / "Restart this game? It will count as a loss.", danger buttons
    "Main menu" / "Restart");
  - the Records replay delete, as an inline table row (`colspan`) on
    --color-danger-fill holding "Delete the replay of <date time>?", a
    danger sm "Delete replay" with a trash icon, and Cancel (shipped: a
    `ui-panel` under the table with a primary coral button);
  - the Settings "Reset all data" confirmation: danger md "Reset all data"
    with a trash icon beside Cancel, not stacked and not full width.
- **Warn and err notes (K15).** `ui-note--warn` (warning ink on
  --color-warning-fill) and `ui-note--err` (danger on --color-danger-fill),
  both radius 8, padding 6px 10px, 14px/700, with a leading info/warning
  icon (task 220's set). Used for:
  - Custom refusals and the 3D no-guess reason on both board choices
    (warn); the density hint, as a warn note inside the board settings
    block under the switch;
  - a board code from the other mode (warn) and a refused board code
    (err, with the field marked `is-invalid` from task 219); the valid
    code's info line is --color-success, bold; the code field placeholder
    is "EN-…";
  - the 3D pointer-lock refusal on the ready card (warn, shipped bare 16px
    warning text);
  - the Settings reset failure line (err), placed under the Reset button,
    copy "The data could not be deleted. Close other tabs of the game and
    try again." (shipped: warning text above the button with per-part
    copy).
- Kit catalogue and gallery show the confirm box and both notes, matching
  J-Components; tests updated for the new copy and parts.
- `.claude/context/app-shell-kit.md` and the pause / records / settings
  context files reflect the new parts and copy where they quote them.

## Decisions
- Canvas artboards to check against: J-Other-states ("Confirmation"),
  J-Pause-states ("Restart confirmation", "Main menu confirmation"),
  J-Records-states (replay delete), J-Settings-states ("Reset all data
  confirmation", reset failure), J-C2D-states and J-C3D-states (refusals,
  board code states), J-Ready-states ("Lock refused …").
- The confirm button copy is the canvas's plain "Confirm" for the pause
  confirmations.
- The board-code copy changes (valid, other-mode and incomplete lines) are
  task 242's (copy alignment); this task restyles the lines only.
- Depends on tasks 218 (danger button) and 220 (icons).
