# Task 165 — Main menu in the shared layout

Target: claude

## Goal
Recompose the main menu, for feature `shared-screen-layout`, from the S3D-Menu
artboard: inside the screen frame on the page backdrop, the title block, the
mode entries (Classic 2D, 3D, Records, Settings, in that order) as an
open-ended column, a scene panel with the orbiting 3D demo board, a column of
the player's headline bests and streak, the key hints for the active input
device, the build label, and the existing Play again and last-played detail
placed in the layout.

## Acceptance criteria
- The menu is built from catalogued components only, with no styling of its
  own beyond placement.
- Each mode entry has its icon, label, detail line and accent; adding a mode
  is adding one entry, with no change to the menu's composition. When the
  entries are taller than their column, the column scrolls on its own and the
  scene panel, bests column and key hints stay in place (a test adds dummy
  entries to prove it).
- The scene panel shows the orbiting demo board through task 164's target
  rectangle; with no WebGL2 the panel shows the backdrop and the 3D entry
  keeps its current fallback.
- The bests column shows, for the last board played in each mode, that board's
  best time, plus the current win streak, from the records stores' read
  interface, and updates on their change notification; a new player sees an
  empty-state line, not zeros.
- Play again and the last-played detail line (`js/shell/returning.js`) keep
  their behaviour and sit where the artboard places them.
- The build label shows the game's real version, not the artboard's
  placeholder.
- Every menu element id, route, the default focus target and controller
  navigation order survive; existing menu, returning and router tests pass,
  updated only where they assert the old arrangement.
- No horizontal scroll at 1024 px wide; contrast checks pass under *Joyful
  tiles*.
- Entries the artboard draws but no milestone has built (Campaign, Daily,
  Hexagon, Triangle, Surface, Leaderboards, Quit) are not shown.

## Decisions
- **Bests column choice** — the last board played in each mode plus the
  current streak, as `shared-screen-layout.md` § Open questions decides;
  revisit when the menu artboard is final.
- **Settled design detail** (`.claude/domain/features/shared-screen-layout.md`
  § Scope, *Main menu*): the empty-state line and the no-WebGL2 panel. The
  feature document is not edited here; task 173 records what holds at ship
  time.
