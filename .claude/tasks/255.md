# Task 255 — Hexagon geometry

Target: claude

## Goal
Part of feature `hexagon-grid`: the hexagon implementation of the flat grid
geometry contract (task 248). Flat-top tiles sit in columns with odd columns
half a tile lower, sized across the flats, with the column and row steps
from the tile size and gap.

## Acceptance criteria
- The geometry answers every query of the contract for a `hex` board: the
  board's extent, each cell's centre, hexagon outline and glyph box (its
  size across the flats), the cell at a board point, and the floor and the
  tile size at each board scale.
- Hit-testing follows the hexagon outline: every point inside the board's
  outline belongs to exactly one cell, and a press in a gap goes to the
  nearest tile.
- The floor is the feature document's value across the flats. The tile size
  at each board scale gives a glyph matching the square's at the floor and
  at the cap.
- Cursor moves: up and down within the column; left and right to the
  adjacent column at the same row index, so the cursor zig-zags along a row;
  none at the board's edge.
- Registered under the `hex` kind in `js/geometry/`, DOM-free, tested in the
  fast tier.
