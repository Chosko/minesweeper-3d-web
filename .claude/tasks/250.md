# Task 250 — Tile painter and cache through the geometry's outline

Target: claude

## Goal
Part of feature `flat-grid-geometry`: the Classic 2D tile painter draws a
cell through its geometry's outline and glyph box, and its cache keys each
image by outline orientation as well as size, pixel ratio, theme and depth.
The square outline is the only one drawn here; the hexagon and triangle
outlines and their theme values are `hex-tri-board-art`'s (tasks 262-264).

## Acceptance criteria
- The painter takes a cell's outline and glyph box from the geometry, and
  the square outline paints exactly the pixels it paints today.
- The cache holds one image per state and outline orientation, so a grid
  with two orientations caches both.
- An unknown state, a number outside the range, or a missing module still
  paints the visible placeholder.
- Tile-skin and tile-art tests pass unchanged, with a new test pinning the
  cache key's orientation part.
