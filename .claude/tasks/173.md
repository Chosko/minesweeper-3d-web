# Task 173 — Update documentation for feature `shared-screen-layout`

Target: claude

## Goal
Feature `shared-screen-layout` recomposed every non-game screen inside the
screen frame from new kit components, gave the 3D renderer a scene panel
target and added the board choice records panel and the menu's bests column.
The documentation describing those screens still describes the m1 low-fidelity
compositions and needs to reflect the shipped layout.

## Acceptance criteria
- `.claude/context/app-shell.md` describes the new kit components and their
  catalogue entries, the screen frame, the menu's composition and bests
  column, the pause card, cards, confirmations and results screen in the
  frame.
- `.claude/context/rendering.md` describes the renderer's target rectangle and
  the scene panel.
- `.claude/context/classic2d.md` and `.claude/context/mode3d.md` describe the
  board choice screens and their records panel; `records.md`, `settings.md`
  and `replay.md` describe their screens in the frame.
- `.claude/context/testing.md` describes the changed and added tests;
  `.claude/context/INDEX.md` rows say what each file covers now, with `Last
  updated` advanced.
- `README.md` changes only where it describes the screens' arrangement.
- `.claude/domain/features/shared-screen-layout.md` records the details tasks
  163–172 settled that hold at ship time (the catalogued component, part and
  slot names, the scene panel's tracking, the menu's empty state), and its
  *Open questions* drops the artboards that were supplied. Nothing else in it
  changes.

## Decisions
- **The `[PLANNED]` m3-on-steam features this layout makes stale**
  (leaderboard-screen, leaderboards-menu-entry, results-steam-rank,
  input-rebinding) are not amended here: `shared-screen-layout.md` § Non-goals
