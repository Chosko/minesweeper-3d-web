# Task 9 — Seeded source and standard mine placer

Target: claude

## Goal
Build the deterministic base of feature `board-generation`: a fixed seeded
pseudo-random source owned by the generator, and the placer that draws a
uniformly random mine set over any cell graph honouring the reference
ruleset's first-click guarantee, with the dense fallback for requests that
allow it. The generator version is defined here and recorded with each
board.

## Acceptance criteria
- A fixed pseudo-random algorithm seeded from a 32-bit (or wider) seed,
  independent of `Math.random` and the platform; a test pins its first
  outputs for a known seed.
- The placer takes a cell graph, a mine count, a first-click cell, a seeded
  source and whether the dense fallback is allowed, and returns a mine set as
  cell indices. The excluded region (the cell, or the cell and its
  neighbours) follows the first-click rule of the reference profile in
  `js/engine/profiles.js`; with the dense fallback allowed and no room for
  the neighbours, only the cell is excluded.
- An impossible request (more mines than the guarantee leaves room for,
  after the fallback when allowed) is rejected at once with a reason.
- Determinism: same request and generator version → same mine set; a test
  pins one Expert board's mine set for a fixed seed.
- A distribution test over many seeds shows every allowed cell can hold a
  mine and no excluded cell ever does.
- A `GENERATOR_VERSION` constant is exported; changing the source or the
  placer's draw order requires bumping it (stated in the module header).
