# Task 182 — Classic 2D tiles drawn from the active theme's board module

Target: claude

## Goal
Draw every Classic 2D tile in the active theme, for feature
`themed-board-art-and-motion`: the shell subscribes to the applier's theme
change, waits for the theme's number font, and hands the board module to the
tile skin, which paints each state through the recipe with the theme's 2D
style, palette and number font and redraws on change. The board view lays
tiles out with the module's gap and corner radius, both scaling with the
tile; the board frame and the ground between tiles come from the theme
stylesheet as a kit component, its radius following the tile size, and the
cursor ring's colour and radius from the board module.

## Acceptance criteria
- The tile skin takes a board module and holds no palette of its own; its
  cache is keyed by theme as well as size and pixel ratio and dropped on a
  theme change, after which the board redraws.
- The shell hands the module on at start-up and on every theme change, only
  after `document.fonts.load` resolves for the theme's number font; no tile is
  cached in a fallback font.
- The board frame is a catalogued kit component styled by every theme's
  stylesheet, its corner radius scaling with the tile; the cursor ring takes
  the board module's colour and its radius follows the tile's.
- **Gap and radius.** The board view places tiles on the tile size plus the
  module's gap (a fraction of the tile), rounds each tile's corners by the
  module's radius, and keeps the fit rule, `MIN_TILE_SIZE`, scrolling and
  pinch zoom working on that pitch; hit-testing maps a pointer anywhere in a
  cell's slot, gap included, to that cell. A theme with no gap and no radius
  draws as today.
- The tile skin, board view and replay 2D viewer never import a theme or read
  a stylesheet (a test greps for it).
- Under *Joyful tiles* the board shows the flat tiles, gap and radius
  J-BoardSheet draws, at 48 px and at the minimum tile; `tests/tile-skin.test.mjs` paints every state from a fixture board
  module, and a browser test switches between *Joyful tiles* and a fixture
  theme mid-game and sees the tiles redraw with no state change.
- Classic 2D fidelity tests pass unchanged.

## Decisions
- **Owner decision** (DESIGN-CHANGES §3.3): the 2D tile's corner radius and
  the gap between tiles scale with the tile; the board view's pitch and
  hit-testing follow. This replaces the edge-to-edge chunky raised tiles
  this task first expected.
- **Settled design detail**
  (`.claude/domain/features/themed-board-art-and-motion.md` § Architecture,
  *Board art hand-off*, *Classic 2D tile skin*): the board frame's catalogue
  name. The feature document is not edited here; task 187 records what holds
  at ship time.
