# Task 277 — Menu previews for Hexagon and Triangle

Target: claude

## Goal
Part of feature `flat-grid-menu-entries`: the focused Hexagon or Triangle
menu entry's scene panel shows the mode's Intermediate board in its board
frame, drawn by the flat board view over the grid's geometry, the same on
every load, like the Classic 2D preview.

## Acceptance criteria
- Each entry's preview data names the board kind with its grid and a seeded
  demo game: Intermediate, partly opened, built from a fixed seed the way the
  Classic 2D demo board is, never stored.
- The preview binder mounts the flat board view for the grid the preview
  names, one view layer per board kind, kept mounted, as for Classic 2D.
- The tag reads "Hexagon · Intermediate" or "Triangle · Intermediate".
- A preview that fails to mount shows the panel's card.
- Menu tests and the component gallery's menu preview pass, with a browser
  test of both new previews.
