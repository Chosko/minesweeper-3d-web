# Task 277 — Menu previews for Hexagon and Triangle

Target: claude

## Goal
Part of feature `flat-grid-menu-entries`: the Hexagon and Triangle play
tiles of the main menu (task 283) each show their own preview at once — the
centre of the mode's Intermediate board, near playing size, drawn by the
flat board view over the grid's geometry on the dark scene background and
cropped so no board edge shows — the same on every load, like the Classic
2D preview. Exact sizes and crops come from the canvas
https://claude.ai/artifact/LeP32jxNxEnHLUtRwJ3FNC — J-Menu-xl, -l, -m, -p
and -states, and J-Components *Main menu buttons*.

## Acceptance criteria
- Each entry's preview data names the board kind with its grid and a seeded
  demo game: Intermediate, partly opened, built from a fixed seed the way the
  Classic 2D demo board is, never stored.
- The preview binder mounts the flat board view for the grid each tile's
  preview names, cropped to the tile, one view layer per tile, kept
  mounted, as for Classic 2D.
- On a phone each preview is a cropped strip inside the right end of the
  mode's row, never setting the row's height.
- No tile shows a Last played chip.
- A preview that fails to mount shows the tile's fallback, as any tile
  preview does.
- Menu tests and the component gallery's menu preview pass, with a browser
  test of both new previews.

## Decisions
- **Re-planned for the play tiles** (design changelog 2026-10-23, "Joyful
  main menu: play tiles with their own previews" and "no Last played
  chip"): the focused entry's scene panel and its tag give way to each
  tile's own cropped preview.
