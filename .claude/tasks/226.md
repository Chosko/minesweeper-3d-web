# Task 226 — 2D tile art: glyphs, hairline, start cell, flat widths and the cursor ring outside the tile

Target: claude

## Goal
Bring the tile art in line with the *Joyful tiles* canvas (Claude Design
artifact https://claude.ai/artifact/LeP32jxNxEnHLUtRwJ3FNC, page "Joyful
tiles"): the mine and wrong-flag glyphs, two-digit 3D numbers and the
revealed hairline drift; the 2D start-cell look and the flat tile widths
are drawn on the canvas but not built; and the 2D cursor ring sits inside
the tile where the canvas draws it outside. Part of the canvas drift
fixes; intended feature: `themed-board-art-and-motion`. Drift ids: K29
(C4, C5, C6, C15), P1 (C18, D28), P2 (C18), C2.

## Acceptance criteria
- **Mine glyph (C4).** Navy #16204a body, 8 spikes ending in round knobs,
  spanning 0.75 of the tile (atlas bbox 31-224 of 256), opaque #ffffff
  highlight — in 2D and the 3D atlas. Shipped: thin spikes, no knobs, 0.79
  span, .85 highlight.
- **Wrong-flag cross (C5).** Its own colour #c62f2f (not --color-danger
  #b42a2a), stroke about 0.057 of the tile (about 0.10 with the white
  outline), butt ends — 2D and atlas.
- **3D two-digit numbers (C6).** 10-26 set at 0.68 of the tile (same
  height as single digits, glyph about 135/256), narrowed to fit; shipped
  0.62.
- **Revealed hairline (C15).** 1 CSS px at every tile size (shipped 1/48 of
  the tile snapped to device pixels, 0.5 CSS px at 26 px on a 2× screen).
- **2D start cell (P1).** Classic 2D draws the marked start cell from the
  theme (`palette.faces2d.marked`): the canvas's teal tile with a dashed
  ring, in the game, the menu preview and the Daily preview (shipped draws
  an outlined square).
- **Flat tile widths (P2).** The flat style takes its widths from the
  module: a .08 inset pressed shade (shipped a .1 band) and a 2px exploded
  tile border, as the canvas draws them.
- **Cursor ring (C2).** The 2D cursor ring draws outside the tile on an
  overlay canvas layer: navy #16204a ring 3px wide sitting 3-6px outside
  the tile, with a 2px white band 1-3px outside; ring radius tile×.15+3; it
  covers none of the tile's face and moves without redrawing cells.
- Tile-art and board-view tests updated; the `[slow]` 2D walk and motion
  tests pass.
- `.claude/context/classic2d-board-view.md`, `classic2d-tile-skin.md` and
  `rendering-board-art.md` describe the overlay ring layer and the new art.
