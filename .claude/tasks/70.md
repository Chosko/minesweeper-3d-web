# Task 70 — Update documentation for feature `replay-recording`

Target: claude

## Goal
Feature `replay-recording` adds the replay format, the recorder and sealer,
the 2D and 3D movement samplers and the replay on the mode contract. The
navigation layer needs to describe the shipped recording.

## Acceptance criteria
- A context file for replays (`.claude/context/replay.md`) describes the
  format, its versioning, the recorder, the samplers and the sealer.
- `.claude/context/app-shell.md` names the replay on the `game finished` and
  `game abandoned` reports; `classic2d.md` and `mode3d.md` name where their
  sessions feed the recorder.
- `.claude/context/testing.md` lists the new tests, fixtures and the
  measurement script; `.claude/context/INDEX.md` covers the new files.
