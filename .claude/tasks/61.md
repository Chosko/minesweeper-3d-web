# Task 61 — 3D board identity, board key and labels

Target: claude

## Goal
Extend `game-summary`'s board vocabulary for feature `3d-game-records`: the
3D board identity (mode 3D, X, Y, Z, mines, no-guess), its key carrying the
mode so it never equals a 2D key, and the 3D labels with the six presets
recognised from their exact size and mine count.

## Acceptance criteria
- The board identity accepts the 3D form — mode 3D, width X, height Y, depth
  Z, mines, no-guess, no grid field — and validates it (each dimension 1 to
  100, mines 1 to cells minus one), throwing a range error otherwise.
- `boardKey` gives a 3D key that carries the mode and never equals a 2D key;
  every Classic 2D key is unchanged. The 3D key form is documented in the
  module as part of the stored records.
- `boardLabel` names the presets "Double layer Beginner / Intermediate /
  Expert" and "Cube Beginner / Intermediate / Expert", with " · no-guess"
  when set, and any other 3D board as "10 × 10 × 10 · 80 mines"; a custom
  board matching a preset exactly is that preset's board.
- Node tests pin the keys and labels of the six presets with and without
  no-guess and of custom 3D boards, and re-pin the m1 2D keys.
