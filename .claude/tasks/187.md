# Task 187 — Update documentation for feature `themed-board-art-and-motion`

Target: claude

## Goal
Feature `themed-board-art-and-motion` made both boards draw from the active
theme's board module through named tile drawing styles, retired the sky tokens
and the 3D atlas's unthemed palette, and added the cell motion player with its
2D layer and 3D mesh. The documentation describing the tile recipe, the tile
skin, the atlas, the sky and the solved pulse still describes one fixed look
and needs to reflect the shipped behaviour.
