# Task 197 — Bare `node --test` runs only the project's tests

Target: claude

## Goal
Run from the repository root, bare `node --test` also picks up the review
script `docs/ux-review/ux-first-run/s7-hit-test.mjs` (it matches Node's
default `*-test.mjs` pattern), which needs a server on port 8080 and so
fails, reporting a failure that is not a project test. The project's suite
command, `.claude/external/run-full-tests.sh`, passes the
`tests/**/*.test.mjs` glob and is unaffected. Bare `node --test` must run
only the project's tests, by the least invasive means: the review script
stops matching Node's default test patterns.

## Acceptance criteria
- `docs/ux-review/ux-first-run/s7-hit-test.mjs` is renamed so it matches
  none of Node's default `--test` patterns (for example
  `s7-hit-check.mjs`), with any reference to it inside `docs/ux-review/`
  updated. No other review script matches today; the rename covers every
  file outside `tests/` that does.
- A fast-tier test (in `tests/affected-tests.test.mjs`, which pins the
  runner scripts) lists the repository's files outside `tests/`,
  `node_modules/` and `.git/` and asserts none matches Node's default test
  patterns (`**/*.test.{js,mjs,cjs}`, `**/*-test.*`, `**/*_test.*`,
  `**/test-*.*`, `**/test.*`, `**/test/**`, each over `.js`, `.mjs`,
  `.cjs`), so a later review script cannot reintroduce the problem. Written
  first, it fails on the current tree.
- Bare `node --test --test-skip-pattern "in a browser"` from the root runs
  exactly the files `.claude/external/run-fast-tests.sh` runs.
- `.claude/context/testing.md` § OVERVIEW states the current rule: no file
  outside `tests/` matches Node's default test patterns (pinned by the new
  test), and the scripts' `tests/**/*.test.mjs` glob stays; the sentence
  saying bare `node --test` picks the review scripts up goes.
- `.claude/external/run-*.sh` are unchanged.
- `docs/UX_REVIEW_DRIFT.md` is a dated review record and keeps its
  observation as written.

## Decisions
- **Rename, not relocate or configure.** One file matches, and Node has no
  project-level config file for the default glob without a `package.json`
  (the project has none and adds none); a rename touches one file.
- **Pinned by a test** rather than only documented, since the next review
  script named `*-test.mjs` would bring the failure back silently.
