# Task 203 — Classic 2D hint strip from the game's start on a touch-only device

Target: claude

## Goal
The Classic 2D first-use hint strip appears only at the first key or
controller press of a 2D game (`used2D` in `js/main.js`, `stripShown`'s
`used` in `js/shell/first-use.js`, `refreshHints`; see
`.claude/context/app-shell-help.md` § First-use hints). A pure-touch player
never presses a key, so never sees the strip's touch wording ("Tap reveal ·
Long-press flag · Tap a number chord"). On a touch-only (coarse-only) device
the strip should show from the game's start, under the same first-use
eligibility (a game inside the mode's first games) and the same dismissal
rule. On a device with a fine pointer nothing changes: the strip still waits
for a key or pad press.

## Acceptance criteria
- On a coarse-only device (`COARSE_ONLY` in `js/main.js`: `(pointer: coarse)`
  and not `(pointer: fine)`), an eligible, undismissed Classic 2D game shows
  the hint strip on its board from the start, before any input, in the
  touch wording.
- An ineligible game (past the first games) or a dismissed strip shows no
  strip on a coarse-only device, exactly as today.
- On a fine-pointer device the strip still appears only at the first key
  or controller press of the game; a mouse click alone does not bring it.
- The one-time scroll hint on a clipped board keeps its precedence over the
  strip on every device.
- **Tests first**: a unit test in tests/shell-first-use.test.mjs pins the
  rule (e.g. `stripShown` with a touch-only flag: shown without `used` on
  touch-only, not without it otherwise; eligibility and dismissal still
  gate both), and a phone browser test in tests/classic2d-touch.test.mjs
  (the `PHONE` context, 390 × 844, `hasTouch`, `isMobile`) starts a fresh
  profile's Classic 2D game and asserts the strip is visible with "Tap
  reveal · Long-press flag · Tap a number chord" before any key, tap or
  pad input. Both fail on the current build.

## Decisions
- **Touch-only is the page's pointer media (`COARSE_ONLY`)**, the same test
  that already picks touch wording, not the last-used active device: the
  strip's start-of-game decision is made before any input exists.
- Settled without conflict: no domain feature document states when the
  Classic 2D strip appears (`.claude/domain/features/game-shell.md` and
  `classic-2d-square-play.md` do not); none changes.
