# Task 268 — Hexagon and Triangle modes with their board choice screens

Target: claude

## Goal
Part of feature `flat-grid-modes`: register Hexagon and Triangle with the
mode host under the ids `hexagon` and `triangle` (the menu entries' ids),
each from its flat mode configuration (task 267), and give each a board
choice screen in the Classic 2D board choice's composition and its own last
board choice.

## Acceptance criteria
- Two configurations: Hexagon from `js/hexagon/board-setup.js` and the
  `hex` grid, Triangle from `js/triangle/board-setup.js` and the `tri`
  grid, each with its display name, last-choice document and board-code
  token.
- Each board choice screen is the Classic 2D board choice's composition
  with its collapsible panel (task 284), its body heading the mode's name:
  by default the Board list — Beginner, Intermediate and Expert with their
  size, mines and density, Custom and Insert Board Code, with no Last
  played chip — and the foot with only Play; the panel with the no-guess
  switch row (shared help text and density hint), Custom's fields, info
  line, refusal and Random, the code field, the chosen board's three bests
  and *All records*; the panel toggle with the stored pin shared by every
  mode; the panel opening on its own for Custom and Insert Board Code; the
  phone drawer. It is routed like Classic 2D's and the shell hands it its
  bests. Exact values: the canvas
  https://claude.ai/artifact/LeP32jxNxEnHLUtRwJ3FNC, J-Hex and J-Tri board
  choice at -xl, -l, -m, -p and -states.
- Each mode's generation client is warmed when its board choice opens.
- The last board choice is one stored document per mode, in Classic 2D's
  shape, versioned through the platform layer. An invalid stored choice
  reads as the mode's default (Beginner, no-guess on) and is never saved.
- The Daily screen still lists Hexagon and Triangle as *Coming soon*, and
  Classic 2D's board choice is unchanged.

## Decisions
- **Re-planned for the collapsible board choice panel** (design changelog
  2026-10-23, "Board choice windows: collapsible panel, all modes"): the
  panel, its pin and the Play-only foot come from task 284's Classic 2D
  board choice, configured per mode, with no code of their own here.
