# Task 300 — Steam build's Data panel says the data is kept on this computer

Target: claude

## Goal
Feature `steam-desktop-host` (§ Architecture, *Where the data is kept, in
words*): the Steam build keeps the player's saves in the user-data
directory, synced by Steam Cloud, never in a browser, yet the Settings Data
panel's line above Reset all data says "Delete everything the game keeps in
this browser and start over as a new player." on both builds. On the Steam
build the line must read "Delete everything the game keeps on this computer
and start over as a new player."; the web build keeps its line unchanged.

## Acceptance criteria
- With the desktop host flag on, the Data panel's line above "Reset all
  data…" reads exactly "Delete everything the game keeps on this computer
  and start over as a new player."
- With the flag off (the web build), the line reads exactly as before:
  "Delete everything the game keeps in this browser and start over as a new
  player."
- The line is chosen from the same desktop host flag that already picks
  Reset all data's confirmation ("from this computer" / "from this
  browser"); no caller tests for Electron or the bridge directly.
- A fast test in `tests/settings-page.test.mjs` checks both builds' line,
  beside the existing test of the two confirmations.

## Decisions
- The Steam line says "on this computer", matching the Steam build's
  confirmation "from this computer", rather than naming Steam Cloud: the two
  texts of one action speak of the same place.
