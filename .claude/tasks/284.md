# Task 284 — Collapsible board choice panel, Classic 2D and 3D

Target: claude

## Goal
For feature `shared-screen-layout` (§ Scope and non-goals, **Board choice
screens**, the panel toggle and the drawer; § Architecture, **Board choice
panel**; § Data and state, the pin): make the Classic 2D and 3D board
choice windows show only the Board list and the foot by default, with the
settings, Custom form, code field and bests in a panel that opens to the
right — pinned by a toggle whose state is a stored preference shared by
every mode, and opened on its own for Custom, Insert Board Code and Learn
3D. Exact sizes, colours and positions come from the canvas
https://claude.ai/artifact/LeP32jxNxEnHLUtRwJ3FNC — J-C2D-xl and
J-C2D-xl-expanded (the reference, interactive in Play), J-C2D-l, -m, -p,
-p-expanded and -states, J-C3D-xl, -l, -m, -p and -states, and
J-Components panel toggle, drawer and stat row.

## Acceptance criteria
- Default: the Board list and the foot only, the window as narrow as its
  content allows. The panel opens to the right of the list; the window
  widens and stays centred.
- The panel toggle — a quiet icon button at the right of the mode heading,
  accessible name *Settings & bests*, pressed state exposed, drawn sunk
  while pinned. Pressing it pins the panel; pressing again unpins it. The
  pin is one stored view preference, saved through the platform layer as
  `records.view` is, shared across sessions and across every mode's board
  choice; unpinned when nothing is stored.
- Selecting Custom, Insert Board Code or Learn 3D opens the panel when it
  is not pinned; selecting a preset closes it again unless pinned; while
  one of those three is selected the panel stays open even when unpinned,
  the toggle then changing only the stored preference.
- The panel holds the board settings, the Custom form (no longer in a
  raised or muted box; 3D's with its Depth field), the code field, the
  bests and *All records* under the bests, which opens Records on the
  selected board and switch as the old footer Records did.
- The foot holds only Play, on the right, the go variant (task 281),
  disabled for Insert Board Code until a code is entered; the summary text
  and the footer Records button are gone.
- No Last played chip on the board options; the last board played is still
  selected when the window opens.
- Phone: no toggle in the head; a full-width drawer under the Board list
  holds the panel — closed a raised bar, open lying flat on a cream band
  ending with a line — labelled *Board settings*, *Board code* or *Learn
  3D*, under the same pin and auto-open rules; the bests a single one-row
  table after the settings; Back, Play and the bottom bar slimmer.
- Keyboard and controller reach the toggle, the drawer and *All records*;
  the hooks the board choice tests use keep their ids or move with them.
- The panel and pin are written so a flat mode configured on the Classic 2D
  board choice (`flat-grid-modes`) gets them with no code of its own.
