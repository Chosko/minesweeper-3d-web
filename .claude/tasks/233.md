# Task 233 — Controls and bindings lists as one ruled two-column part

Target: claude

## Goal
The *Joyful tiles* canvas (Claude Design artifact
https://claude.ai/artifact/LeP32jxNxEnHLUtRwJ3FNC, page "Joyful tiles")
draws every controls list — the pause card, the 3D ready card (desktop and
touch), the H help card and the Settings bindings — as one ruled
two-column list with short rows. Shipped uses long sentence rows, kbd
boxes and unruled grids, which makes the H panel 888px tall. Part of the
canvas drift fixes; feature: `shared-screen-layout`. Drift ids:
K32 (F24, G1, G2, G20, H2-32).

## Acceptance criteria
- One kit list part: 15px, rows padding 5-6px 0, a 1px --color-line rule
  on top of each row, key in bold ink on the left as plain words (no kbd
  boxes), action muted and right-aligned.
- Fed with the canvas's short rows:
  - **Pause, desktop:** 9 rows from "Left / middle button — Reveal" to "F2
    — Restart" (as drawn on J-Pause-xl). **Pause, phone:** 5 rows: "Tap —
    Reveal (or flag on Tap: Flag)", "Long-press", "Tap a number", "One
    finger — Pan a large board", "Pinch — Zoom". Heading "Controls" 22px;
    the aside uses only the inset 2px border (no 6px edge).
  - **3D ready card, desktop:** "Mouse — look around", "W A S D — fly",
    "Q / E — down / up", "Left / Right — reveal / flag", "Wheel —
    spacing", "Shift · Space · Ctrl — view modes". **Touch:** "Left thumb —
    fly", "Drag — look", "Tap — reveal", "Long-press — flag", "Two-finger
    tap — chord", "Pinch — spacing".
  - **H help card (3D):** a card 320 wide (radius 22, 8px yellow head-edge,
    elevation-2), padding 18px 20px; title "Controls" 22px heavy ink, not
    uppercase; eleven ruled rows; foot "H hides this panel." 14px.
  - **Settings bindings:** rows `key | action` with short copy ("Reveal",
    "Flag", "Look around (click to capture)"), keys as plain bold words
    ("W A S D", "Space / Enter"), no extra "Middle click" row unless the
    canvas draws it.
- The rows come from the bindings source so rebinding still updates them;
  where the canvas's short wording drops information a test relied on,
  the test changes to the new wording.
- Bindings, pause, ready, help and Settings tests updated.
- `.claude/context/settings-bindings.md`, `app-shell-help.md` and
  `app-shell-pause.md` reflect the list part and copy.

## Decisions
