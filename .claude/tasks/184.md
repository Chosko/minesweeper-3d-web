# Task 184 — Cell motion player

Target: claude

## Goal
Add the one DOM-free cell motion player both renderers use, for feature
`themed-board-art-and-motion`: started by a cell event with the cell, the
event, the visual states before and after and the theme's description, it
answers per frame each animating cell's current scale, offset, rotation and
face shown, depth, brightness and opacity, and drops everything when the
board, a seek, a pause or a theme change says so.

## Acceptance criteria
- Interface: `start(cell, event, before, after, description)`,
  `valuesAt(time)` → each animating cell's values, `dropAll()`, `animating()`.
- Tracks interpolate their keyframes with the description's easing (named
  curves and cubic Bézier); a flip shows the before state until its midpoint
  and the after state from then on; a cell shows its after state once its
  animation ends.
- A second event on an animating cell restarts it from the new state.
- A cap on concurrent animations: past it a cell shows its new state at once.
  The cap is measured (a flood reveal on a 100 × 100 board, both renderers)
  and set with the measurement noted in the module.
- A `null` description starts nothing.
- The player never touches game state, the timer or a replay;
  `tests/cell-motion.test.mjs` covers interpolation, easing, flip midpoint,
  restart, the cap and dropping; the player reads no settings field and no
  media query.

## Decisions
- **Module path** `js/cell-motion.js`, beside `js/tile-art.js`, the other
  module both renderers share.
- **No reduced-motion handling** (2026-10-13): reduced motion is deferred
  whole to `m7-after-launch` (`themed-board-art-and-motion.md` § Scope and
  non-goals), reversing the reading that the player follows the operating
  system's preference meanwhile; cell motion always plays until then. The
  precondition on task 160 stays dropped: it was there only for a
  reduced-motion setting.
- **Settled design detail**
  (`.claude/domain/features/themed-board-art-and-motion.md` § Architecture,
  *Cell motion player*): the measured cap and the interface names. The feature
  document is not edited here; task 187 records what holds at ship time.
