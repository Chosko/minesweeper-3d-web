# Task 280 — Hexagon and Triangle daily boards on the Daily screen

Target: claude

## Goal
Part of feature `flat-grid-menu-entries`: Hexagon and Triangle each get a
daily board, worked out from the date like the Classic 2D and 3D ones and
played from the Daily screen. Each is the mode's Expert board with
no-guess, the same for everyone on that local date, started on its marked
start cell, with one counted attempt, its days in a row and its code, so
the Daily screen's two rows stop reading *Coming soon*.

## Acceptance criteria
- The daily board list gains a Hexagon and a Triangle entry, each the
  mode's Expert board with no-guess on its grid, named by its dimensions
  like the existing entries. `dailyGame` gives for each date its seed (the
  daily seed over the board's token), the marked start cell of its graph,
  its daily code and a generation request on the `hex` or `tri`
  description. The Classic 2D and 3D daily boards' seeds and codes do not
  change.
- A Hexagon daily code reads `HEN-<YYYYMMDD>-<check>` and a Triangle one
  `TEN-<YYYYMMDD>-<check>`: the frozen daily form over the tokens of tasks
  256 and 260. Today's code typed into a board choice or opened as a
  `#board=` link opens the Daily screen; another day's code is a challenge
  in its mode.
- The Daily screen lists every menu mode in menu order, with Hexagon and
  Triangle playable as the Classic 2D row is: board line, state (*Not
  played*, *Won* with its time, *Lost*), days in a row and the longest run,
  the code chip with Copy and Copy link, Play while today's counted attempt
  is unused, Watch replay once won when the library kept the replay.
  Surface stays *Coming soon*.
- The selected Hexagon or Triangle row's preview is the closed daily board
  with its marked start cell, drawn by the flat board view over the mode's
  grid; a preview that fails to mount shows the panel's card.
- Today's unused Hexagon and Triangle boards are pre-generated when the menu
  shows, through each mode's warm generation client, and the menu never
  waits for them. Play takes the held board, or generates it, and starts it
  through the mode's coded start (task 270): forced on the marked cell, no
  last choice saved, one counted attempt, the results screen after.
- A Hexagon or Triangle daily game is recorded on its mode's Daily board:
  the Records picker lists it after the mode's standard boards, with its
  days in a row, as for Classic 2D and 3D.
- Node tests pin the two new daily games and the unchanged existing ones
  (`records-board-code`), the Daily rows, panels and counted attempt
  (`shell-daily`), today's and another day's Hexagon code (`shell-challenge`)
  and the Daily option in the Hexagon and Triangle pickers
  (`records-screen`). A browser test plays today's Hexagon daily from the
  Daily screen to its results and finds the row *Won* or *Lost*.

## Decisions
- The daily code is the frozen grammar's daily form over the mode's board
  token (`HEN`, `TEN`). The design canvas draws the Hexagon daily as
  `HX-20261016-3C9E`; like its `EC-…` 3D code, that is an illustration of
  the form, not a new code shape (`records-board-code.js`'s header: the
  grammar only gains shapes through tokens).
- The daily boards are this feature's: the grid features define the tokens
  and the identity's daily flag, and `flat-grid-records-replays` records a
  daily game on its mode's Daily board as for any mode.
