# Task 26 — Main menu entries and the last mode played

Target: claude

## Goal
Give feature `game-shell` its m1 main menu: four entries — Classic 2D, 3D,
Records and Settings — each a route, composed from the screen kit over the
decorative 3D demo backdrop, and keep which mode the player last started
through platform storage.

## Acceptance criteria
- The main menu shows Classic 2D, 3D, Records and Settings, in that order,
  built from kit components, with the 3D demo board as backdrop.
- 3D opens the existing 3D presets and custom board; Classic 2D, Records and
  Settings route to their screens, and to a "coming soon" placeholder screen
  with Back while their feature has not landed.
- Starting a game in any mode records the mode in a `shell.lastMode`
  document registered with `platform-storage` at version 1.
- Every entry is operable by mouse, keyboard and controller with the menu's
  declared default focus.
- Playwright checks the four entries, their routes and Back.

## Decisions
- Screens whose feature has not landed route to one shared placeholder
  screen, so the menu is complete now and each later feature only swaps its
  route target.
