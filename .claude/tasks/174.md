# Task 174 — Live figures model: 3BV progress, pace vs PB, 3BV/s, clicks and flags

Target: claude

## Goal
Add the DOM-free live figures model of feature `in-game-layout`: given a
game's counts (3BV, 3BV solved, clicks, flags, mines), the elapsed time and
the board's bests, it returns each figure's text and detail line, so both
modes and the replay viewer show the same figures computed the same way.

## Acceptance criteria
- **3BV** — `solved / total` with a progress fraction for the bar.
- **Pace vs PB** — elapsed time minus the personal best time scaled by the
  share of the board's 3BV solved; negative is ahead, shown signed with its
  unit. Absent when the board has no best time, and before the first 3BV is
  solved.
- **3BV/s** — 3BV solved per elapsed second, with the board's best 3BV/s as
  its detail line; no detail line when the board has none.
- **Clicks** — the counted clicks, with the live efficiency as its detail
  line, using `game-summary`'s efficiency definition.
- **Flags** — flags placed, with mines left as its detail line.
- Formats match the existing results and Records formatting helpers; a figure
  the inputs cannot yet produce (zero elapsed time) returns a neutral
  placeholder, never `NaN` or `Infinity`.
- A change helper reports which figures' text changed between two inputs, so
  the overlay writes only those.
- `tests/live-figures.test.mjs` covers every figure, a board with and without
  bests, the zero cases, ahead and behind pace, and the efficiency matching
  the game summary's for the same counts.

## Decisions
- **Module path** `js/shell/live-figures.js`, beside the other shell modules
  both modes use.
- **Settled design detail** (`.claude/domain/features/in-game-layout.md` §
  Architecture, *Live figures model*, *Pace vs PB*): the module path and the
  neutral placeholder. The feature document is not edited here; task 179
  records what holds at ship time.
