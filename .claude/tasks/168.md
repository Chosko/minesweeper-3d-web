# Task 168 — Pause card, generating and failed-board cards, placeholder and confirmations in the shared layout

Target: claude

## Goal
Recompose the pause card, the generating and failed-board cards of both
modes, the placeholder screen — the *Coming soon* page Hexagon, Triangle and
Surface open — and the confirmations, for feature `shared-screen-layout`, as
J-Pause-xl/-l/-m/-p, J-Pause-states and J-Other-xl/-l/-m/-p and
J-Other-states draw them, keeping the content and behaviour their owning
features define.

## Acceptance criteria
- Each is composed from its artboards using catalogued components only.
- **Pause card** in play (2D and 3D), with no game (before the first click,
  ended), and its restart and main-menu confirmations, as J-Pause-states
  draws them.
- **Placeholder screen** (`#coming-soon`): the screen frame with Back (Esc),
  the mode's name as its title and "This part of the game is coming soon.",
  as J-Other draws it; it names the mode it was opened for (task 165 passes
  it).
- **Confirmations** ("Leave this game?" with Confirm and Cancel, and the
  pause card's) as J-Other-states draws them.
- Pause, resume, restart and leave rules, the Esc rule, the generating
  card's progress and cancellation and the failure offer behave as before.
- Every element id (including `#pause-card`, `#c2d-wait`, `#c2d-offer`,
  `#m3d-wait`, `#m3d-offer`, `#coming-soon`), route, default focus and
  controller navigation target survives; existing tests are updated only
  where they assert the old arrangement, and pass.
- No horizontal scroll at any supported window size; contrast checks pass
  under *Joyful tiles*.

## Decisions
- **Its artboards exist** — J-Pause-* and J-Other-* on the canvas — so the
  manual intervention this task carried while they were undrawn is gone and
  the task is `claude`.
- **The placeholder is the Coming soon page** (owner decision,
  DESIGN-CHANGES §2.1): it is what an unbuilt mode's menu entry opens.
- Toasts, the fatal card, the no-JavaScript notice and the 404 page, also on
  J-Other, are task 211's.
