# Task 282 — Window title bar and game logo on every screen

Target: claude

## Goal
For feature `shared-screen-layout` (§ Scope and non-goals, the screen frame
and the game logo, **The title bar's window buttons on the web**;
§ Architecture, **Screen frame**): make the screen frame's head the game's
own title bar on every desktop window — main menu, every board choice,
Daily, Records, Settings, the replay viewer, the placeholder and the
in-game windows — and move each screen's name into a body heading. Exact
sizes, colours and positions come from the canvas
https://claude.ai/artifact/LeP32jxNxEnHLUtRwJ3FNC — J-Components section
*Window title bar, confirm and cancel buttons, panel toggle, drawer*, row
*Game title · title-bar logo*; J-Logo-proposals 4a (at rest); J-C2D-xl as
the reference screen; and each screen's artboards.

## Acceptance criteria
- The head holds Back on the left as an arrow icon only (none on the main
  menu), the straight game logo in the centre (the letters in the game
  colours, a white outline and a short darker extrusion), and Minimise,
  Fullscreen / Windowed and Quit on the right; every one is icon-only with
  a tooltip and an accessible name.
- On the web Minimise, Fullscreen / Windowed and Quit press like any
  button and then do nothing — no action, no message, no confirmation, no
  lock. Phones show only Back and the logo in the head.
- The window buttons read the platform layer's capability flags so the
  desktop host can attach its actions (`steam-desktop-host`,
  `leaderboards-menu-entry`); with no host they stay inert. Quit uses the
  stop variant (task 281).
- Each screen's name is a heading at the top of the window body; a control
  that sat at the right of the old header moves to the right of that
  heading — Records' 2D | 3D mode switch, and a slot for the board choice
  panel toggle (task 284). The main menu has no body heading.
- The large game title (`ui-wordmark`) above the windows is removed on
  every screen and the windows move up into the freed space; the main menu
  window grows taller.
- The kit catalogue names the logo and the frame's new parts; Back and the
  stable hooks keep their ids and default focus, or move with their owners;
  keyboard and controller reach every title-bar button.
- The bouncy logo and its start animation are not built.

## Decisions
- **The in-game windows' own content** (Pause in Back's place, mode in the
  footer) is `in-game-layout`'s; this task gives them the title bar's
  frame head only.
