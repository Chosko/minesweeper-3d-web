# Task 19 — Main menu, pause card and results layout from the kit

Target: claude

## Goal
Compose the m1 screens of feature `screen-components` from the kit: rebuild
the main menu and the pause card from components, replacing the shell's
one-off styles, and provide the results screen's layout composition that
`results-screen` fills with content — all in both themes.

## Acceptance criteria
- The main menu and the pause card in `index.html` use only kit components;
  the one-off rules they replace are removed from `css/style.css`.
- A results-screen layout (card, stat readouts, primary and secondary
  buttons) exists as a composition in the kit, with placeholder content, for
  `results-screen` to fill.
- Every control has an accessible name and a visible focus; keyboard and
  controller navigation reach every control in the existing order.
- The existing 3D game flow (menu → ready → playing → pause → menu) works as
  before; the `window.__ms` hook is unchanged.
- Playwright screenshots of the menu, pause card and results layout in both
  themes pass the contrast check.
