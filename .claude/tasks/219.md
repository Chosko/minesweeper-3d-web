# Task 219 — Kit form controls: switch, switch row, slider fill, number field, invalid state, focus halo

Target: claude

## Goal
Bring the kit's form controls in line with the *Joyful tiles* canvas
(Claude Design artifact https://claude.ai/artifact/LeP32jxNxEnHLUtRwJ3FNC,
page "Joyful tiles"; classes `j-switch`, `j-switchrow`, `j-input`,
`j-seg`, `j-check`, `j-tab`, `j-label`, `j-badge`). A design review found
the switch, slider, number field and the small controls drift from it, the
invalid field state is missing, and the decided focus ring is not applied
everywhere. Part of the canvas drift fixes; feature:
`shared-screen-layout`. Drift ids: K13 (B11, B12, B16, E3, E20, F23,
H2-28, H2-29), K14 (B14, B15, E13), K21 (B17, B18, B19, B26, H1-39,
H1-47), E25, B13.

## Acceptance criteria
- **Switch (K13).** 60×34, knob 24px at left 5 (on: left 31); on touch
  sizes (p, ls) 64×38 with a 28px knob (shipped 44×24, knob 16 at 4/24).
  Focus: outline 3px #16204a, offset 4, halo `0 0 0 10px #ffc93c`, and no
  inset border while focused (shipped offset 3, halo 9px, and the off
  switch keeps its inset 2px muted border).
- **Switch row (K13).** A `ui-switchrow` part (canvas `.j-switchrow`):
  label (18px/700 ink) with its help line (14px muted) stacked on the left,
  the switch at the right edge. When the switch is locked the label stays
  ink at 18px/700 (shipped greys the whole toggle to `--color-locked-ink`).
  The kit, catalogue and gallery show it. (Screens adopt it in their own
  tasks; Settings rows and the pause Sound row use it.)
- **Slider (K13).** Track 8px #f3dca0 (--color-line) with a fill in
  --color-teal-edge #2a9488 from the start to the thumb, driven by a CSS
  custom property the kit sets on the input (a small fill updater in the
  kit keeps it in step on input and on programmatic value changes). Thumb
  26px. The value is 16px JetBrains Mono 700, min-width 64, right-aligned,
  on the same row after the track (gap 14); the label sits above that row.
  Shipped: no fill, 20px thumb, value on the label's row above a
  full-width track.
- **Number field (K14).** Height 48, padding 0 14px, 19px JetBrains Mono
  700, radius 12, border 2px #8a7a5c (shipped min-height 44 + padding
  8px 12px, 16px, width 96). An `is-invalid` state: border --color-danger
  #b42a2a and `box-shadow: 0 0 0 3px #ffe1de` (--color-danger-fill), in the
  kit, catalogue and gallery. Custom refusals in both board choices
  (`js/classic2d/board-choice.js`, `js/mode3d/board-choice.js`) mark the
  offending field `is-invalid` instead of `data-adjusted`.
- **Small kit metrics (K21).** Segmented option padding 7px 14px,
  15px/700, radius 10; disabled segmented option and disabled tab are
  locked ink with no strike-through. Checkbox label 15px/700, gap 8
  (shipped 16px regular, gap 12). Badge (`.ui-chip` used as Won / Lost /
  Abandoned) padding 3px 8px, letter-spacing .06em, gap 6. Tab padding
  9px 14px; the selected tab has ink text and a 3px accent underline with
  no fill. Section label (`.ui-heading` as canvas `.j-label`) 13px,
  letter-spacing .2em (shipped 14px, 2.24px).
- **Selected option at open (E25).** The theme styles the board option's
  focus ring on `:focus-visible`, not `:focus`, so a selected option
  opened by mouse keeps its resting 5px --color-blue-edge drop instead of
  showing flush with translateY(5px).
- **Focus halo (B13, decided).** Every focusable control takes the
  switch's ring — 3px navy outline plus the yellow halo — including the
  segmented option, slider, link, tab and checkbox, which have no halo
  today.
- The rendered gallery matches J-Components for these parts; kit tests
  cover the switch row, the slider fill, `is-invalid` and the focus halo;
  the board-choice tests expect `is-invalid` on refusals.
- `.claude/context/app-shell-kit.md` names the switch row, the slider fill
  updater and the invalid state.

## Decisions
- Canvas artboards to check against: J-Components (form controls), J-C2D-states
  and J-C3D-states (Custom refusal, invalid field), J-Settings-xl (sliders,
  switches), J-Pause-xl (Sound and Volume rows).
- Owner decision 18: apply the decided focus-ring halo to segmented,
  slider, link, tab and checkbox (rather than revising the decision).
- The shipped field `data-adjusted` (warning fill) state is not drawn on
  the canvas; refusals use `is-invalid` instead.
- Depends on task 214 (reliable full suite).
