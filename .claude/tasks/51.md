# Task 51 — Box graph provider

Target: claude

## Goal
Add the 3D box to the shared engine's topology for feature `3d-board-graph`:
a graph provider that builds the cell graph of an X × Y × Z box with the
26-neighbourhood clipped at the edges, and maps between a cell index and its
(i, j, k) coordinates, keeping the index layout and neighbour order the 3D
renderer, picking and camera are written against.

## Acceptance criteria
- A DOM-free ES module builds the box graph from X, Y and Z, each an integer
  from 1 to 100; anything else throws a `RangeError`.
- The index layout is the current one (`idx = i + X*(j + Y*k)`, i fastest),
  with `index(i, j, k)` and `coords(idx)` mapping both ways.
- Neighbour order matches the current 3D engine's enumeration (di outer, dk
  inner); a test pins it for a corner, an edge, a face and an interior cell.
- Neighbours are enumerated from fixed index offsets with edge clipping, not
  stored as per-cell lists: building a 100 × 100 × 100 graph allocates no
  per-cell object.
- The provider plugs into the engine's cell-graph interface, so the rules
  engine, the generator's placer and the solver accept it unchanged.
- Node tests cover neighbour counts (7 / 11 / 17 / 26), symmetry of the
  neighbour relation, index round-trips, and 1 × 1 × 1 and 1 × 1 × N boxes.
- `js/logic.js` is not changed.
