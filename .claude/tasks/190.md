# Task 190 — Daily screen won time in the standard time format

Target: claude

## Goal
For feature `game-shell`, show a won daily row's time in the game's standard
time format, to the thousandth of a second ("Won 48.213 s"), the format the
results, Records and leaderboard screens use, in place of the tenths it shows
now ("Won 48.2 s").

## Acceptance criteria
- A won row on the Daily screen reads `Won <time>` with the time formatted by
  the results screen's `formatTime` (e.g. "Won 48.213 s"); *Not played* and
  *Lost* are unchanged.
- The local `tenths` helper in `js/shell/daily.js` is removed, and no other
  Daily text still shows tenths.
- `tests/shell-daily.test.mjs` asserts the new format, including a time with
  trailing zeros (e.g. 47.380 s).
