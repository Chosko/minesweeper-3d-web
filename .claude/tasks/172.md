# Task 172 — Replay viewer in the shared layout

Target: claude

## Goal
Recompose the replay viewer's chrome, for feature `shared-screen-layout`,
inside the screen frame from catalogued components — the playback controls,
seek bar with the pause spans, overlay figures and failure and end lines —
with the 2D board inside the frame and the 3D scene full-window as today,
keeping the behaviour `replay-playback` defines, as J-Replay-xl/-l/-m/-p and
J-Replay-states draw it; the live figures beside the controls are
`in-game-layout`'s (task 178).

## Acceptance criteria
- The viewer is composed from its artboards using catalogued components
  only, in every state J-Replay-states draws (opening, failure, playing, at
  the end, Show 3BV on, 3D with Free camera).
- Opening and verifying, controls, keys and controller buttons, seeking and
  the end line behave as before; the 3D replay scene stays full-window.
- Every element id (`#replay`, `#replay-board`, `#replay-message`,
  `#replay-controls` and the rest), route, default focus and controller
  navigation target survives; existing replay viewer tests pass, updated only
  where they assert the old arrangement.
- No horizontal scroll at any supported window size; contrast checks pass under *Joyful
  tiles*.

## Decisions
- **Its artboards exist** — J-Replay-* on the canvas — so the manual
  intervention this task carried while the artboard was undrawn is gone and
  the task is `claude`.
