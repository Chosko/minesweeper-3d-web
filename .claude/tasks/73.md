# Task 73 — End-of-game hand-off to the replay library

Target: claude

## Goal
Connect feature `replay-library` to the game shell's end of game: every
finished and abandoned game's sealed replay is added to the library after
its summary is recorded, pinned when the game set a personal best, and kept
in memory for the session when it cannot be saved.

## Acceptance criteria
- On `game finished(summary, replay)` and `game abandoned(summary, replay)`
  the hand-off records the summary with `personal-records` first, then calls
  the library's `add` with the replay's listing fields and whether the
  comparison shows any of the board's three bests was set.
- A replay that could not be saved, or a session where nothing persists,
  still leaves the just-finished replay available for the session, so the
  results screen can play it.
- A dropped replay (recorder failure) adds nothing and does not affect the
  summary or the records.
- Node tests cover the order (record, then add), best pinning from the
  comparison, and the session-only fallback, with fakes.
