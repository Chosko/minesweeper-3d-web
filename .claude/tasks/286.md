# Task 286 — Classic 2D game window: title bar with Pause, mode in the footer, collapsed live figures

Target: claude

## Goal
For feature `in-game-layout` (§ Scope and non-goals, **Classic 2D game
window**, **The live figures panel**, **Restart in the strip**; § Data and
state): while playing, the Classic 2D window shows only the board and the
two counters. Pause takes Back's place in the title bar, the mode and
difficulty lead the footer, Swap clicks and the live-figures toggle sit at
the footer's right, the live figures panel is hidden by default with its
open state remembered across sessions and modes, and Restart is icon-only.
Exact sizes, colours and positions come from the canvas
https://claude.ai/artifact/LeP32jxNxEnHLUtRwJ3FNC — J-Game2D at -xl, -l,
-m, -p, -ls and -states (each states board's second frame shows the panel
open).

## Acceptance criteria
- Title bar (task 282's): Pause in Back's place, the logo in the centre, no
  mode or difficulty in it, and no heading in the body.
- Footer line: the mode and difficulty lead the board line (size, mines,
  no-guess); Swap clicks moves from the header to the footer's right, next
  to the live-figures toggle.
- Live figures panel hidden by default: the window shrinks to the board and
  stays centred. The toggle (accessible name *Live figures*, pressed state
  exposed, drawn sunk while open) opens it beside the board as before. Its
  open or closed state is one stored view preference beside the board
  choice pin (task 284), shared by every mode and kept across sessions;
  closed when nothing is stored.
- Always visible: the mines-left and time counters with Restart between
  them. Restart is icon-only, accessible name and tooltip *Restart*, with
  no text and no F2 label; the F2 shortcut is unchanged.
- Phones, portrait and landscape: Pause and the logo in the head, the mode
  and difficulty leading the footer line, no live-figures toggle (the
  panel stays hidden there).
- The overlay's hooks (time, mines, clicks, Pause, the board-size label)
  keep their ids or move with their owners; keyboard and controller reach
  the toggle and Swap clicks in the footer.
- The window is written so the flat modes (`flat-grid-modes`), which use
  this window, get every change with no code of their own.

  c) A "Live figures" switch on the pause card, which the controller already walks, sets the same stored preference. The foot's controls stay mouse and keyboard only.
  d) No controller route in this task: ship keyboard reach only and file a follow-up task for the controller.
