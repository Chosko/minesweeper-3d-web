# Task 170 — Records screen in the shared layout, with its Leaderboards tab

Target: claude

## Goal
Recompose the Records screen, for feature `shared-screen-layout`, as
J-Records-xl/-l/-m/-p and J-Records-states draw it — the 2D | 3D switch, the
board picker, the figures as stat tiles, the averages, both charts, and the
tabs Recent games, Top 10, Replays and the new Leaderboards — keeping the
content and rules `records-screen` and `3d-results-records-screens` define.
The Leaderboards tab shows the "Leaderboards are coming soon" panel and no
pager until `leaderboards-menu-entry` fills it.

## Acceptance criteria
- The screen is composed from its artboards using catalogued components
  only.
- **Tabs:** Recent games, Top 10, Replays, Leaderboards, in that order; the
  Leaderboards tab shows the coming-soon panel as J-Records-states draws it,
  with no pager, for every board; it is reachable by mouse, keyboard and
  controller like the other tabs.
- **3D picker:** the four cube presets (task 212), Daily and custom boards;
  no First box entry.
- The mode switch, board picker, opening mode and board, live update, empty
  state, filters, chart hover, pagination and the library view's Pin /
  Unpin / Watch / Delete behave as before.
- Every element id (the `rec-*` and `ro-*` figures included), route, default
  focus and controller navigation target survives; Records tests are
  updated first for the fourth tab and the arrangement, and pass.
- No horizontal scroll at any supported window size (the averages stacked
  at phone width); contrast checks pass under *Joyful tiles*.

## Decisions
- 2026-10-19: no longer waits on task 207, skipped when the First box
  removal moved to this feature; it waits on task 212, which replaces it
  with the same goal.
- **Owner decision** (DESIGN-CHANGES §2.2, §4.7): Leaderboards leaves the
  main menu and becomes Records' fourth tab, a coming-soon panel until the
  leaderboards exist.
- **Its artboards exist** — J-Records-* on the canvas — so the manual
  intervention this task carried while the artboard was undrawn is gone and
  the task is `claude`.
