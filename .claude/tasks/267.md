# Task 267 — Flat mode configuration, with Classic 2D as the square configuration

Target: claude

## Goal
Part of feature `flat-grid-modes`: make the shipped Classic 2D flow a
template a mode configures with its grid, rather than writing two more
modes. A flat mode configuration holds what differs between the three flat
modes: mode id and display name, grid kind (graph provider and geometry),
standard sizes and custom limits, the last-choice document, and the
board-code token. The Classic 2D mode, board setup, board choice binder and
last-choice store take a configuration where they assume the square grid.
Classic 2D becomes the square configuration and plays exactly as it does.

## Acceptance criteria
- A configuration is immutable. An unknown grid kind, or standard sizes
  outside the configuration's own custom limits, throws at registration.
- `createClassic2DMode`, `boardSetup`, `bindBoardChoice` and
  `createLastChoice` take a configuration; Classic 2D passes the square one,
  built from `js/classic2d/board-setup.js`'s values and the square geometry.
- The session, view, inputs, sampler, generation client and pre-generation
  are built per mode instance from its configuration. Instances share the
  page's button swap and the board scale setting.
- Classic 2D's stored last choice, board codes, records keys and replays are
  unchanged. The shipped Classic 2D, shell and fidelity tests pass
  unchanged.
