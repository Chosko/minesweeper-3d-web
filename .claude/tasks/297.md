# Task 297 — Update documentation for feature `settings`

Target: claude

## Goal
Feature `settings` splits the saved settings into the settings document and
a machine settings document, carries the two machine values over once from
an old settings document, and keeps the loose-key carry-over and its reset
to the browser build. The navigation layer describing the store, Reset all
data and the documents' owners is out of date and needs to reflect the
shipped behaviour.

## Acceptance criteria
- `.claude/context/settings.md` describes the two documents, which settings
  each holds, the one-time carry-over from an old settings document and the
  browser-only loose-key carry-over.
- `.claude/context/settings-reset.md` says the loose keys are removed on the
  browser build only.
- `.claude/context/platform.md`'s list of the documents' owners names the
  machine settings document.
- `.claude/context/INDEX.md`'s rows for those files match them.
