# Task 245 — Update documentation for feature `in-game-layout`

Target: claude

## Goal
Feature `in-game-layout` brought the game window in line with the *Joyful
tiles* canvas: the Classic 2D window hugging its content with the board
under the counter strip and a flat figures column, the HUD following the
frame's size steps in 2D and 3D, the negative counter in the danger colour,
the first-use hint strip laid over the board, the touch Tap: Reveal / Flag
segmented choice, and Learn 3D's own play layout and end cards. Each task
updated the context file of its own area; this task brings the
documentation layer as a whole up to date with what shipped.

## Acceptance criteria
- The context files under Files describe the shipped window, HUD, hint
  strip, Tap choice and Learn 3D layout, with no passage still describing
  the replaced look (the viewport-filling window, the board refit under the
  hint strip, the single latched Tap toggle, Learn 3D's full game HUD).
- `.claude/context/testing.md` describes the changed and added tests;
  `.claude/context/INDEX.md` rows say what each file covers now, with
  `Last updated` advanced.
- `.claude/domain/features/in-game-layout.md` records the details tasks
  231, 232 and 236 settled that hold at ship time. Nothing else in it
  changes.
- The documentation states no value the code holds (rule 10 of CLAUDE.md
  § Editing Discipline).

## Decisions
- **The 3D HUD readouts and the touch stick are documented by task 244**,
  whose task 235 built them under `shared-screen-layout`; this task covers
  the in-game window parts of tasks 231, 232 and 236.
