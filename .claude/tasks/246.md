Target: claude

## Goal
Feature `themed-board-art-and-motion` brought the boards in line with the
*Joyful tiles* canvas: separate Classic 2D and 3D number lists in the board
module, the Classic 2D end effect driven by the module, the theme
stylesheet's scene tokens renamed and its stale board tokens retired, the
opacity, flip, scale and brightness motion tracks with the canvas
keyframes, the redrawn mine and wrong-flag glyphs, the constant revealed
hairline, the flat style's widths from the module, the Classic 2D marked
start cell, the cursor ring outside the tile on its own layer, and the
plain board frame around every Classic 2D board. Each task updated the
context file of its own area; this task brings the documentation layer as
a whole up to date with what shipped.

  end effect, the inside cursor ring or the unframed previews.
- `.claude/context/testing.md` describes the changed and added tests;
  `.claude/context/INDEX.md` rows say what each file covers now, with
  `Last updated` advanced.

  details tasks 224–227 settled that hold at ship time (the module fields

- The documentation states no value the code holds (rule 10 of CLAUDE.md
