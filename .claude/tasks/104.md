# Task 104 — Leaderboard screen: board picker, scope tabs, entries and states

Target: claude

## Goal
Build the leaderboard screen of feature `leaderboard-screen` as a
game-shell route: the board picker, the Global, Friends and Around me tabs,
the entry list with the player's own row highlighted, the own standing bar,
paging through Global, and the loading, empty, offline, unavailable and
web-build local-only states — all reading `steam-leaderboards`.

## Acceptance criteria
- The route opens with an optional board identity: that board, else the
  board last viewed this session, else Classic 2D Expert with no-guess off;
  Back returns to the caller.
- Board picker: 2D | 3D switch, the mode's catalogue boards and a no-guess
  switch; only catalogue boards are offered.
- Tabs Global (default), Friends and Around me; each row shows rank, player
  name, time to the tenth (`47.3 s`), 3BV/s and efficiency from the entry's
  details, and a *Watch replay* button disabled without a replay (wired in
  task 105). The player's own row is highlighted in every scope.
- Global loads one page at a time with *More*; Friends shows the whole
  list; Around me shows a range either side of the player. The page size and
  range are set at real list heights.
- Own standing bar: time, in the same format as the rows, and global and
  friends rank, or "no time yet".
- Every time on the screen is truncated to the tenth, never rounded
  (an entry of 47 380 ms shows as `47.3 s`), through the results screen's
  time formatter (task 46) rather than a second copy; the Node tests check
  a row's and the bar's time.
- States: loading; empty; offline with a retry; Steam unavailable; and in
  the web build a "local only" label with Friends and Around me hidden. A
  failed fetch never leaves the screen unusable; Back always works.
- Every control is reachable by keyboard and controller; shoulder buttons
  switch scope; Esc and the back button mean Back.
- `.claude/domain/features/leaderboard-screen.md` and
  `.claude/domain/features/steam-leaderboards.md` record the page size and
  the Around me range in place of their open questions. Nothing else in
  either document changes.
- Node tests drive the screen's state with a fake leaderboards module;
  Playwright checks the web build's local-only screen.

## Decisions
- Settled here: the global page size and the Around me range
  (`.claude/domain/features/leaderboard-screen.md` § Open questions and
  `.claude/domain/features/steam-leaderboards.md` § Open questions). Both
  are normally `/architect`'s; this task updates them for exactly this and
  for nothing else.
- The screen's time format is `results-screen`'s, per
  `leaderboard-screen.md` § Architecture (Entry list).
