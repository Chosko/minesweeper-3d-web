# Task 57 — 3D game session: safe first click, generation and timer

Target: claude

## Goal
Build the 3D game session of feature `3d-play-flow`: one 3D game from a
closed box to a result, with the board generated in the worker around the
first reveal, a "generating" state while it waits, the timer starting when
the board is ready, and the first-click guarantee and no-guess failure
handled as Classic 2D handles them.

## Acceptance criteria
- The session builds the box graph and a game awaiting its first click from
  the board choice and shows the closed box.
- The first reveal sends a request to the generation worker with the pinned
  first-click rule and the no-guess setting; while it waits the session shows
  the "generating" state and accepts no board action; when the board arrives
  it applies the reveal and starts the timer, keeping the seed and generator
  version.
- The first-click guarantee is Classic 2D's pinned rule: the clicked cell
  alone is mine-free, so the first click is safe but not always an opening;
  the request never fails for density below the mine cap of every cell but
  one. A no-guess request that exhausts its budget is handled by the rule
  `board-generation` records, as Classic 2D does.
- Flags placed before the first reveal are kept; a left release on a flagged
  cell or a chord before it does not start the timer. The timer shows two
  decimals as today and stops at a win or loss.
- Restart and leave cancel a pending generation; a pause during generation
  keeps the request running and the timer unstarted.
- Actions come from the existing mouse state machine and controller mapping,
  unchanged.
- The old per-size best times in browser storage are neither read nor
  written, and are left where they are.
- Node tests cover the session with a fake worker (first click, generating,
  flags before the first reveal, cancel); Playwright plays a preset game
  through the worker.

## Decisions
- This session replaces task 54's synchronous main-thread placement; the 3D
  game no longer calls the placer directly.
