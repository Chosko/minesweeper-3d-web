# Task 167 — 3D board choice screen in the shared layout

Target: claude

## Goal
Recompose the 3D board choice screen, for feature `shared-screen-layout`, as
J-C3D-xl/-l/-m/-p and J-C3D-states draw it, with the composition task 166
builds for Classic 2D: on the left Learn 3D first, the four cube presets
(task 207) with no group label, Custom and, after a divider, *Insert Board
Code*; on the right how 3D works for Learn 3D, the no-guess switch and the
board's three bests for a preset, the four-field Custom form with *Random*,
or only the code field; the bottom bar with *Records* and *Play*.

## Acceptance criteria
- The screen is composed from catalogued components only, sharing task
  166's composition.
- **Window.** The game title on top; the window sized to its content and,
  being taller than the 2D one, starting just under the title at every
  desktop size.
- **Left.** Learn 3D first (its own accent outline and cube badge), Cube
  Intro, Cube Beginner, Cube Intermediate, Cube Expert, Custom, a divider,
  *Insert Board Code*. Each preset shows name, size line and mine density,
  and the Last played chip beside the name; nothing from the records.
- **Right, Learn 3D:** only "How 3D works" (its three lines) and the note
  that the lesson keeps no records — no switch, no bests.
- **Right, a preset:** the no-guess switch and "<board> · <no-guess> · your
  bests" with Time, 3BV/s and Efficiency tiles, each with its date or "no
  best yet", following the switch that governs the board.
- **Right, Custom:** the custom no-guess switch with its reason when
  unavailable ("No-guess isn't available when a side is 2 cells", "No-guess
  is available up to 8,000 cells"), then Width, Height, Depth, Mines, the
  info line, *Random* and the refusal line, then the bests for that size.
- **Right, Insert Board Code:** only the code field and its feedback; a
  Classic 2D code shows the hint naming the Classic 2D board choice.
- **Bottom bar:** summary, *Records* (opens Records on the selected 3D board
  and switch, Back returning here) and *Play*, disabled on a refused custom
  size and on an empty or refused code; *Play* on Learn 3D starts the
  guided board without saving a choice.
- **Phone** (J-C3D-p): as task 166's phone layout; it scrolls past the fold.
- The no-guess limit, no no-guess on a side of 2, Random fill, custom
  limits, Learn 3D's start and the last 3D board choice document behave as
  before.
- Every surviving element id, route, default focus and controller
  navigation target survives or moves with its owner; 3D board choice, code
  and returning tests are updated first and pass.
- No horizontal scroll at any supported window size; contrast checks pass
  under *Joyful tiles*.

## Decisions
- **Same pattern as Classic 2D** (owner's answer: "Replicate as 2D does"),
  now the J-C2D composition of task 166.
- **Its artboards exist** — J-C3D-* on the canvas — so the manual
  intervention this task carried while the artboard was undrawn is gone and
  the task is `claude`; Learn 3D's right side and the single unlabelled
  preset group come from them (owner decisions, DESIGN-CHANGES §2.4, §4.3).
- **The board code** is the fifth option played with *Play*
  (DESIGN-CHANGES §2.5), replacing *Play this board*.
