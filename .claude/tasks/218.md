# Task 218 — Kit buttons: md size, key hint ink, quiet variant, latched toggles, danger variant

Target: claude

## Goal
Bring the kit's buttons (`.ui-button` in `css/components.css`, themed in
`themes/joyful-tiles/theme.css`) in line with the *Joyful tiles* canvas
(Claude Design artifact https://claude.ai/artifact/LeP32jxNxEnHLUtRwJ3FNC,
page "Joyful tiles"; its CSS classes are `j-btn`, `j-btn--md`,
`j-btn--quiet`, `j-btn--danger`, `j-key`). A design review found the
default size, the key hints inside buttons, the quiet and danger variants
and the latched toggles drift from it on every screen. Part of the canvas
drift fixes; intended feature: `shared-screen-layout` (the kit the
redesigned screens use). Drift ids: K1 (A6, B1, B35, E6, G25, H1-21,
H2-16), K2 (A5, B6, E7, G26, H2-13), K3 (B4, B2, F9), the danger part of
K16 (B28, H2-34).

## Acceptance criteria
- **Key hint ink (K1).** A key hint inside a button (`.ui-button
  .ui-key-hint` and its key/`kbd`) takes the button's own colour
  (`currentColor`): ink #16204a on coral primary and on cream secondary,
  for the key text and a 1.5px `currentColor` border. Key font-size is
  `max(11px, .72em)`. Shipped draws it muted #5a6385 with `.78em` because
  the key inherits `.ui-key-hint{color: ink-muted}`.
- **Default (md) size (K2).** The default button is the canvas's md: 17px,
  weight 800, padding 10px 18px, min-height 46, icon/label gap 10,
  line-height 1.1 (shipped 16px, 12px 20px, 44, gap 8, line-height 1).
  sm and lg keep their sizes but take gap 10 and line-height 1.1. The
  replay speed segmented options are 15px with padding 7px 14px.
- **Quiet variant (K3).** `ui-button--quiet` exists in the kit, the kit
  catalogue (`js/ui/kit-catalogue.js`) and the component gallery
  (`dev/components.html`), md and sm, default / selected / pressed /
  disabled: white surface, `inset 0 0 0 2px #ece2d0` (--color-border), no
  drop edge; selected has no lift, fill #fbf1df (surface-sunk) and
  `inset 0 0 0 2px #d6c6ab`; pressed is translateY(2px).
- **Latched toggles (K3).** A latched toggle is a quiet sm button when off
  and a primary sm button (coral #ff6b6b with its #c9403f 4px accent edge,
  ink text) when on — not the shipped secondary-then-blue (#3563d8 with
  #22409a edge) of `.ui-button--secondary[aria-pressed="true"]`. This
  applies to Swap clicks (Classic 2D), the touch view-mode buttons in 3D,
  Show 3BV and Free camera in the replay viewer.
- **Danger variant (K16 part).** `ui-button--danger` exists in the kit,
  catalogue and gallery: fill #b42a2a (--color-danger), white text, dark-red
  #7d1c1c drop edge. Records' "Delete replay" confirm button
  (`#records-replays-yes`, shipped primary coral) and Settings' "Reset all
  data" confirm button use it. (The confirm box around them is task 221's.)
- The rendered gallery matches the J-Components artboard for buttons, key
  hints, toggles and the danger button; existing kit and screen tests pass,
  and kit tests cover the quiet and danger variants and the latched-toggle
  states.
- `.claude/context/app-shell-kit.md` (and `app-shell-kit-helpers.md` if it
  lists variants) names the new variants.

## Decisions
- Canvas artboards to check against: J-Components (buttons, "In game /
  Feedback" toggles), J-Game2D-states ("Swap clicks on"), J-Replay-states
  ("Show 3BV on", "3D · Free camera"), J-Settings-states ("Reset all data
  confirmation"), J-Other-states ("Confirmation").
- Depends on task 214 so the full suite is reliable before the kit
  changes it.
