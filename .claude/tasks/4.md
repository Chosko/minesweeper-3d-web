# Task 4 — Cell graph and square-grid provider

Target: claude

## Goal
Lay the topology layer of feature `cell-graph-rules-engine`: the immutable
cell graph every board is described by (a cell count and, per cell, its
neighbour list over a dense integer index) and the first graph provider, the
8-neighbour square grid on a width × height rectangle, with its mapping
between a cell index and its column and row.

## Acceptance criteria
- A DOM-free ES module builds an immutable cell graph from a cell count and
  per-cell neighbour lists, stored flat (typed arrays) so a large custom
  board is built without per-cell allocation; it is shared read-only by the
  engine, the generator and the renderer.
- The square-grid provider builds the graph for width × height, with
  `index(col, row)` and `colRow(index)` mapping both ways.
- Neighbour order is fixed and documented in the module (generation and
  flood-fill order depend on it); a test pins it for a corner, an edge and an
  interior cell.
- Invalid dimensions (non-integer, below 1) throw a `RangeError`.
- Node tests cover neighbour counts (3 / 5 / 8), symmetry of the neighbour
  relation, index round-trips, and a 1 × 1 and a 1 × N board.
- `js/logic.js` (the 3D engine) is not changed.
