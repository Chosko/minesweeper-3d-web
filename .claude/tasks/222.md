# Task 222 — Kit surfaces: plain stat tile, muted panel, tables, pager, code chip

Target: claude

## Goal
The *Joyful tiles* canvas (Claude Design artifact
https://claude.ai/artifact/LeP32jxNxEnHLUtRwJ3FNC, page "Joyful tiles";
classes `j-stat`, `j-stat--warm`, `j-stat--best`, `j-panel--muted`,
`j-pager`, `j-chip`/code chip, `j-label`) draws a plain stat tile, a muted
panel, ruled tables, a lighter pager and a compact code chip; the kit
lacks or differs on each, so screens use the warm tile, white panels and
full-size buttons. Fix the kit parts; the screens adopt them in their own
tasks. Part of the canvas drift fixes; feature:
`shared-screen-layout`. Drift ids: K12 (B9, B10, E4, H1-9, H1-10, H1-11,
H1-12, H1-13, H1-28), K19 kit part (E11, E21, H1-27, H1-32), K20 kit part
(B24, B25, H1-15, H1-31, H1-41), K18 (B8, H1-43), K17 (B7, D21, H1-18,
H2-7).

## Acceptance criteria
- **Stat tile (K12).** The default tile is plain: white, `inset 0 0 0 2px
  #ece2d0`, no drop, radius 16, padding 14px 16px, gap 3-4px. Warm (cream
  #fff6e8 with the 6px edge) stays as a variant. Label 14px/700 muted,
  sentence case (shipped 12px uppercase, .06em). Note (detail) 13-14px
  Rubik 700, not JetBrains Mono; "was …" in success colour; a worse delta
  is ink-muted, not danger red. New best is `inset 0 0 0 3px #ffc93c`
  (--color-head) keeping radius 16, note "New best" (shipped: 3px success
  outline offset 4, radius 8, plus a chip). Phone: value 24px, padding
  12px. A note can carry an inline "Watch" link (Records bests: "9 Oct
  2026 · Watch").
- **Muted panel (K19).** `ui-panel--muted`: --color-surface-sunk fill,
  padding 14px 16px, gap 8-10, no border and no drop; radius as the canvas
  (20 where the Records overall block draws it).
- **Tables (K20).** The kit table (`ui-table`) draws: header row text 12px
  uppercase .1em tracking; row labels 700 ink sentence case; values
  JetBrains Mono right-aligned; cell padding 8px; a 1px --color-line rule
  across the full row width (not on the value cell only); a rank `#`
  column at 14px JetBrains Mono muted; on phones a details table can stack
  label over value (column, gap 2px). A recent-games table variant has
  columns Date / Outcome / Time with the outcome badge in the middle and
  no board column; dates mono 13px muted on one line; board codes as plain
  mono 13px text (no chip).
- **Pager (K18).** Buttons 38px tall, min-width 38, padding 0 10px, radius
  10, weight 700, edge `0 3px 0 #d6c6ab`, gap 6. Current page: ink fill,
  no shadow. Disabled: locked fill, no shadow. (Shipped: 44px secondary
  buttons, radius 12, weight 800, 4px edges.)
- **Code chip (K17).** Chip 40px tall, gap 6, padding 5px 5px 5px 12px,
  radius 12, a sunk pill; code 15px JetBrains Mono bold. Copy and Copy link
  are quiet compact buttons (task 218's quiet variant): min-height 30,
  padding 4px 10px, radius 9, 13px, each with its 14px icon (copy, link;
  task 220). No inline "Board code" label: the label sits outside as a
  section label "BOARD CODE" (13px, .2em tracking, accent #b8323a); on
  phones the label sits above and the chip runs full width and wraps.
  `createCodeChip` produces this shape for every caller (Daily, results,
  replay, Records).
- Kit catalogue and gallery show each part and match J-Components; kit
  tests updated.
- `.claude/context/app-shell-kit.md` / `app-shell-kit-helpers.md` reflect
  the new variants and the chip shape.
