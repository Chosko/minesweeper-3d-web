Design artifact https://claude.ai/artifact/LeP32jxNxEnHLUtRwJ3FNC, page

- **Won result (D20).** A "WON" badge, then a separate "48.213 s" in

  row (shipped one uppercase chip "WON 48.213 S").
- **Board code (D21).** Task 222's code chip with the "BOARD CODE" section
  label above; on the phone the label above and the chip full width.

  mode list and the detail.
- **Panels (D17, D18).** The 3D, Hexagon and No-WebGL scene panel is 100%
