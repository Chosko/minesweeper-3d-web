# Task 185 — Classic 2D cell motion: motion layer and event sources

Target: claude

## Goal
Play the theme's cell motion on the Classic 2D board, for feature
`themed-board-art-and-motion`: animating cells are drawn on a layer above the
board canvas from the cached tile images, transformed per the motion player's
values, while the board canvas shows the cell's slot empty; events come from
the pointer and cursor inputs' pressed set (press, release, chord press) and
the engine's change lists (reveal, flag, unflag), and the replay viewer plays
the same events from its frames.

## Acceptance criteria
- A motion layer canvas over the board draws only animating cells, with frames
  running only while a cell animates; nothing on the board canvas is redrawn
  per frame.
- Depth draws from cached in-between faces at a few fixed steps; the tile
  cache holds them per theme, size and pixel ratio.
- Press, release and chord press come from the pressed set; reveal, flag and
  unflag from the engine's change lists; Classic 2D has no solved pulse.
- Motion is visual only: hit testing uses the logical slot, no input waits,
  and the game, timer and replay are identical with motion on or off (a test
  plays the same inputs both ways and compares state and replay bytes).
- Motion drops on a new board, a seek, a pause hiding the board and a theme
  change; cell motion ignores the operating system's reduce-motion
  preference.
- A flood reveal on a 100 × 100 board stays within the frame budget measured
  in task 184.
- Classic 2D fidelity tests pass unchanged.
