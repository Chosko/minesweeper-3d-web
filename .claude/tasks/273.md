# Task 273 — Records screen's mode switch over four modes

Target: claude

## Goal
Part of feature `flat-grid-records-replays`: the Records screen switches
between Classic 2D, Hexagon, Triangle and 3D in menu order, as the canvas's
Records artboards draw it, and every part of the screen works per mode as it
does for Classic 2D.

## Acceptance criteria
- `RECORDS_MODES` lists Classic 2D, Hexagon, Triangle and 3D in that order,
  drawn as the kit's segmented control; Surface is not listed. The overall
  row is titled for the mode ("Hexagon overall").
- Records opens on the mode and board last played. `show` takes any of the
  four modes; an unknown mode opens Classic 2D.
- The board picker, bests, counters, averages, history charts, Recent
  games, Top 10, the Replays tab and exports work per mode. A mode without a
  daily board lists none. The Leaderboards tab keeps its *coming soon* state
  for Hexagon and Triangle boards.
- The controller: LB / RB step boards as today; LT / RT step to the previous
  / next mode in the switch's order and stop at either end, changing nothing
  there.
- Records-screen tests, including the controller's, pass with the new
  modes.

## Decisions
- **LT / RT with four modes (user decision, 2026-10-21):** they step to the
  previous / next mode in switch order, stopping at the ends, like LB / RB
  over boards, instead of jumping to Classic 2D and 3D. This settles what
  the feature document leaves as "work per mode as they do for Classic 2D".
  `TRIGGER_MODES` becomes a step rule rather than a mode per trigger.
