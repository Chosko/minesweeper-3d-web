# Task 217 — UX-review scripts follow the current board-choice markup

Target: claude

## Goal
The Playwright scripts under `docs/ux-review/` drive the game through
selectors that no longer exist or no longer do what they did. The Classic
2D board choice's start button `#c2d-start` is gone (its Play button is
`#c2d-play`), and a click on a board preset (`[data-preset="…"]` on the 3D
board choice `#board-choice`, and the Classic 2D presets) now only selects
that board: the game starts from the Play button (`#bc-play` on the 3D
board choice, `#c2d-play` on Classic 2D). Bring every script back in step
with the current markup so a later UX review can rerun them. This is test
tooling and belongs to no feature.

## Acceptance criteria
- No script under `docs/ux-review/` references `#c2d-start`; each former
  use clicks `#c2d-play` instead.
- Every script that clicks a 3D board preset to start a game clicks
  `#bc-play` after the preset click (and every Classic 2D preset click that
  expects a game clicks `#c2d-play` after it), so the game starts as the
  script expects. A preset click that only inspects the selection (for
  example the focus and `data-last` checks in
  `mode-3d/s9-choice-wheel.mjs`) gets no Play click.
- Each changed script parses (`node --check <file>`); at least one changed
  script from each folder that has a dev-server run documented in
  `docs/ux-review/README.md` runs to its end against the current build, or
  the closing report names why it could not.
- No other behaviour of the scripts changes, and no game code changes.
