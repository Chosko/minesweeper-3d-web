# Task 263 — Board module per-grid shape, numbers to 12, checks, and Joyful tiles' values

Target: claude

## Goal
Part of feature `hex-tri-board-art`: the board module's 2D style gains a
gap and corner radius per grid (square, hexagon, triangle), and the 2D
number list runs 1-12. `checkBoardModule` holds every theme to the
legibility and contrast contract on each grid. *Joyful tiles* gets the
values drawn on the Claude Design canvas's Hexagon and Triangle board
sheets, in the same change, because once the checks require the new
entries the catalogue's only theme fails the conformance suite without
them.

## Acceptance criteria
- The board module's 2D style holds gap and radius as fractions of the tile
  for each of square, hexagon and triangle. Every other 2D value is shared
  by the three grids. The 3D style and number list are untouched.
- The 2D number list runs 1-12; a hexagon board shows 1-6, a square 1-8 and
  a triangle 1-12.
- `checkBoardModule` checks per grid: every entry present; each number at
  least 4.5:1 against the revealed face and its shade; the cursor ring at
  least 3:1 against the closed and revealed faces; the closed face's relief
  at least a pixel; every number and glyph legible at that grid's own floor
  (from the geometries of tasks 255 and 259). A module missing a grid's
  entries fails the conformance suite.
- `themes/joyful-tiles/board.js` carries the canvas's values (Hexagon and
  Triangle board sheets, kept variant "B · Sharp"): hexagon gap 6 % and
  radius 5 % of the tile across the flats; triangle gap 6 % and radius 6 %
  of the tile height; numbers 9-12 in the 3D hues of the same numbers. Each
  value carries a comment naming its sheet, as the shipped entries do.
- The test-only fixture themes carry the new entries; the theme
  conformance, board module and registry tests pass.

## Decisions
- **Joyful tiles' hexagon and triangle art is a task of this feature, not a
  later `/theme-implement` run.** The feature document puts the values in
  scope, and the checks this task adds would fail the theme without them, so
  they ship in one commit. Read the values from the canvas as data:
  https://claude.ai/artifact/LeP32jxNxEnHLUtRwJ3FNC, page "Joyful tiles",
  the Hexagon and Triangle board sheets.
