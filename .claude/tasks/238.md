# Task 238 — Records screen to the canvas

Target: claude

## Goal
Bring the Records screen in line with the *Joyful tiles* canvas (Claude
Design artifact https://claude.ai/artifact/LeP32jxNxEnHLUtRwJ3FNC, page
"Joyful tiles"). A design review found the frame, picker, left column,
counters, averages, charts, empty state, tables, replays library and
phone layout drift, and the one-row desktop tables are not built. Part of
the canvas drift fixes; feature: `shared-screen-layout`. Drift
ids: H1-24 to H1-41, H1-43 to H1-46, the Records part of K33, P4 (H1-48).

## Acceptance criteria
- **Frame (H1-24).** 1640×940 at top 66 centred at xl (1302×712 at l,
  984×728 at m, inset 20 at m), not full height.
- **Back (H1-25).** "← Main menu [Esc]" with the arrow icon.
- **Picker (H1-26).** One line, left-aligned with the body (no space taken
  by the hidden LB glyph), clipped with a 40px fade to surface at the
  right; options 15px, padding 7px 14px. Order: Beginner, Intermediate,
  Expert, the three no-guess boards, "Daily", then custom boards. The
  Daily option reads "Daily".
- **Left column (H1-27).** No panels: sections sit on the frame under
  section labels "<BOARD> · BESTS", "COUNTERS", "AVERAGES · WON GAMES";
  only the overall block is a muted panel. The right column has no
  "HISTORY" panel heading.
- **Bests (H1-28).** Plain tiles (task 222): label "Best time" 14px
  sentence case, value 32px, note "9 Oct 2026 · Watch" (13px sans, inline
  Watch link replacing the separate button); 3 across at 1024 too.
- **Counters (H1-29, H1-30).** A "Counters" label and a 14px gap under the
  tiles; a 4-column grid of sunk tiles (surface-sunk, radius 12, padding
  8px 10px), label 13px/700 muted sentence case, value JetBrains Mono
  20px/700 ink; labels "Win rate, completed" and "Best streak, completed".
- **Averages (H1-31).** Header "LAST 10 / LAST 50 / ALL" (12px, .1em);
  row labels 700 ink sentence case ("Time"); values right-aligned mono;
  cell padding 8px. Win rate as one mono 14px line: "Win rate, last 50:
  66% (completed games 72%)". Phone: one card per stat.
- **Overall (H1-32).** Muted panel, radius 20, padding 12px 14px; label
  "CLASSIC 2D OVERALL" then one mono 14px sentence: "Games 1,207 · Wins
  702 · Win rate 58% (completed 66%) · Current streak 7 · Longest 12
  (completed 14)".
- **Exports (H1-33).** Download icons on both export buttons.
- **History (H1-34 to H1-37).** Period and Outcome are inline hug-width
  segmented controls on one row; won-only note 13px; at 1024 the two charts
  stack in the right column and each column scrolls on its own; an empty
  chart draws only the centred text "No won games on this board yet, so
  there is nothing to chart." (no axes or ticks).
- **Empty board (H1-38).** Bests show "—", counters 0 / —, averages
  dashes; filters, note and both empty charts stay; the list reads "No
  games on this board yet."
- **Tabs and Leaderboards (H1-39, H1-40).** Tabs per task 219. The
  Leaderboards panel: a trophy icon chip, title "Leaderboards are coming
  soon" 20px/800 ink sentence case, a muted 15px line.
- **Tables (H1-41, P4).** Recent games and Top 10: date mono 13px muted on
  one line ("16 Oct 2026 14:02"); board code plain mono 13px text (no
  chip); header "Eff."; Replay column a quiet sm "Watch" with a grid icon;
  Top 10 has a "Rank by" label before its segmented control and "#" as the
  rank header; the outcome badge never overruns into the Time cell. At
  desktop sizes each table row is one row (P4), not stacked.
- **Pager (H1-43).** Task 222's pager.
- **Replays library (H1-44).** Columns Date, Outcome, Time, 3BV/s, Eff.,
  Pin (an accent pin glyph, or a locked-edge glyph when not pinned), Board
  code, Actions. Actions are quiet sm icon buttons: Watch, Download,
  Pin/Unpin, and an icon-only trash. "Open replay file" sits at the right
  with an upload icon; the "Pinned first" check box is the kit's.
- **Delete (H1-45).** Task 221's inline confirm row.
- **Phone (H1-46).** The head holds "← Back" and the title only; the
  Classic 2D | 3D switch is a full-width bar below the head; the picker is
  one horizontally scrolling line; bests 3 across; counters 2-column sunk
  tiles.
- Records tests updated; renders match the artboards.
- `.claude/context/records-screen-view.md`, `records-screen.md` and
  `records-library-view.md` reflect the screen.
