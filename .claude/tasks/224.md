# Task 224 — Board module: 2D numbers, 2D end effect from the module, theme token cleanup

Target: claude

## Goal
The board module (`js/themes/board-module.js` contract,
`themes/joyful-tiles/board.js`) has one `numbers` list serving 2D and 3D,
so Classic 2D draws the 3D number colours; the Classic 2D end effect reads
CSS tokens instead of the module; and the *Joyful tiles* stylesheet keeps
board tokens from the old palette and misnames the scene tokens. Fix all
three against the *Joyful tiles* canvas (Claude Design artifact
https://claude.ai/artifact/LeP32jxNxEnHLUtRwJ3FNC, page "Joyful tiles").
Part of the canvas drift fixes; intended feature:
`themed-board-art-and-motion`. Drift ids: K27 (C1, C12, C13, C14), K30
(A21, A22, A23, A24, C16, C17, B34).

## Acceptance criteria
- **2D numbers (C1).** The module contract carries separate 2D and 3D
  number lists. Classic 2D draws 1-8 from the 2D list: 1 #1565c0,
  2 #2b742f, 3 #c32727, 4 #1a237e, 5 #8d1c1c, 6 #00717c, 7 #212121,
  8 #666666 (the `--color-number-1..8` tokens). 3D keeps its list
  (#135bad, #26692a, #ac2626, #1a237e, #8d1c1c, #00656f, #212121, #5c5c5c
  and its 1-26 atlas colours).
- **2D end effect from the module (C12-C14).** `js/classic2d/end-effect.js`
  reads the module, not tokens:
  - win confetti uses `palette.confetti` (coral #ff6b6b, yellow #ffc93c,
    teal #49c6b8, blue #78aaf8, violet #6d4ee8, white, orange #ff8c42),
    not `--color-number-1..7`;
  - the win wave is a scale bump to 1.2 and a mix 0.4 toward white per
    tile, clipped to the rounded tile (radius .15 of the tile), not a
    square `fillRect` in `--color-tile-bevel-light` painting over corners
    and the ground;
  - the loss wave snaps each tile to its revealed face with an overshoot
    from 0.55 and a .55 white flash as the wave arrives.
- **Tokens (K30).** In `themes/joyful-tiles/theme.css`:
  - declare `--color-tile-pressed` #6b9ef2 and `--color-number-8` #666666;
  - rename `--color-panel-night/glow/ink` to `--color-scene-zenith`
    #0e1640, `--color-scene-horizon` #2b3f8a, `--color-scene-ink` #dfe6ff,
    and add `--color-scene-nadir` #1a265f (every reader updated);
  - set `--color-board-frame` #ffffff, `--color-tile-cursor` #16204a,
    `--color-tile-closed` #78aaf8;
  - retire the tokens the canvas lacks once nothing reads them:
    `--color-tile-bevel-light`, `--color-board-gap`, `--color-board-shadow`,
    `--color-board-scrollbar`, `--color-replay-pointer-outline`,
    `--color-replay-bbbv-1..6`, `--color-replay-bbbv-isolated`,
    `--board-frame-radius` (those still read by the replay viewer or board
    frame stay until tasks 227 and 239 stop reading them; this task retires
    what it frees and names the rest in its closing report);
  - 3D closed-cube right bevel exactly #5e92ec (shipped mixes to #5f91eb);
  - base text weight 500 (`--font-weight-regular`) and line-height 1.25.
- The theme contract and conformance tests require the new 2D list and
  tokens; board art and end-effect tests updated; the theme contract
  documentation lists the change.
- `.claude/context/app-shell-board-module.md`, `classic2d-tile-skin.md`,
  `rendering-board-art.md` and `app-shell-themes.md` reflect the split
  lists, the end effect's source and the token names.
