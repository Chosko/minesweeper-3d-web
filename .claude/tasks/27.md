# Task 27 — Pause controller, restart, back to menu and game hand-offs

Target: claude

## Goal
Add the shared in-game flow of feature `game-shell`: one pause controller for
every mode and every pause source, restart and back to menu with their
loss confirmations, automatic pause on focus loss and tab hide, the web
build's leave-page guard, and the hand-off of finished and abandoned games.

## Acceptance criteria
- The pause controller is the one owner of pause, from Esc, the controller's
  Start button, the overlay's pause button, window blur and tab hide; it
  asks the active mode to pause, shows the pause card over a hidden board,
  and resumes through the mode.
- Pause applies only to a started, unfinished game; before the first click
  or after the game ends, the pause key opens the pause card without a timer
  to stop, offering restart and back to menu.
- Restart starts a new game with the same board choice; back to menu leaves
  the mode. During a started, unfinished game each asks for confirmation,
  saying the game will count as a loss.
- Automatic pause fires on blur and on `visibilitychange` to hidden during a
  started, unfinished game; the leave-page guard (`beforeunload`) is armed
  only then.
- `game finished(summary)` routes to the results route with the summary;
  `game abandoned(summary)` passes the summary to a records hook and goes
  where the player asked, with no results screen. Both hooks are attachment
  points the results and records features fill.
- Node tests cover the pause rules and confirmations with a fake mode;
  Playwright checks pause / resume / restart / menu in 3D.
