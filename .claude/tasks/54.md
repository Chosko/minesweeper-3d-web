# Task 54 — 3D front-end on the shared engine and retirement of the 3D engine

Target: claude

## Goal
Complete feature `3d-board-graph` by switching the existing 3D game to the
box graph, the 3D rule profile and the 3D state view, then removing the
separate 3D engine `js/logic.js` and its tests, with the scene, camera and
controls unchanged.

## Acceptance criteria
- The 3D game creates its game on the shared engine with the box graph and
  the 3D profile, awaiting the first click; the first reveal's board request
  is answered by `board-generation`'s standard placer around that cell, from
  its seeded source.
- `js/render.js`, `js/picking.js` and the HUD read the 3D state view; hidden
  cells still cannot be picked; the scene's look and the mouse and controller
  gestures are unchanged.
- Custom 3D boards accept at most cells minus one mines.
- `js/logic.js` and `tests/logic.test.mjs` are deleted, and nothing in the
  repository imports them.
- The full test suite passes; a Playwright run via `window.__ms` plays a 3D
  game from a fixed mine set to a win and to a loss.

## Decisions
- The board for the first reveal is placed synchronously on the main thread
  by the standard placer. This is the engine swap only: the worker, the
  "generating" state, the no-guess switch and the timer rules are
  `3d-play-flow`'s session, which replaces this call.
- The `__ms` debug hook keeps accepting a fixed mine set, now passed to the
  engine's create-from-mine-set, so Playwright boards stay deterministic.
