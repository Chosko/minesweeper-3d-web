# Task 242 — Copy alignment with the canvas

Target: claude

## Goal
Adopt the *Joyful tiles* canvas wording (Claude Design artifact
https://claude.ai/artifact/LeP32jxNxEnHLUtRwJ3FNC, page "Joyful tiles")
for the toasts, board code lines, summaries, refusals, foot line, ready
tip, results lines and live figure notes, where shipped copy was drafted
independently. Part of the canvas drift fixes; feature:
`shared-screen-layout`. Drift ids: K36 (A16, A17, E15, E16, E18, F17, G9,
H1-2, H1-17), F16, G24, H2-10, A18.

## Acceptance criteria
- **Toasts.** Theme fallback: "The theme could not be loaded. The game uses
  Joyful tiles." Settings not saved: "Settings could not be saved in this
  browser. They last until you close the page."
- **Version toast (A18).** Keep the two reasons (newer: reload to update;
  older: cannot be rebuilt), restyled to the canvas's sentence form ("This
  board code is from another version of the game. …"), the newer case
  keeping its reload action.
- **Board code lines (E15).** Valid: "Intermediate · 16 × 16 · 40 mines ·
  no-guess · starts on the marked cell" (3D: "… starts on the marked
  cube"). Other mode: "This is a 3D board code. Paste it in the 3D board
  choice." and its Classic 2D mirror. Truncated: "This code is incomplete:
  it is missing its last part." — `parseBoardCode` gains an incomplete
  reason.
- **Summary (E16).** "Board code · Intermediate · 16 × 16 · 40 mines ·
  no-guess" (same pattern in 3D).
- **Refusals (E18).** No final period ("… on a 30 × 16 board", "… make it
  at least 2 cells").
- **Foot line (F17).** "16 × 16 · 40 mines · No-guess".
- **Ready tip (G9).** "Tip: press F for fullscreen, so the browser passes
  Ctrl+W to the game." 14px muted plain text, no kbd boxes.
- **Results (H1-2, H1-17).** The board line carries the mode: "Classic 2D ·
  Intermediate · no-guess", "3D · Cube Intermediate · no-guess". Equal to
  best: "best 94.7% · equal" (not "= best").
- **Live figure notes (F16, G24, H2-10).** Pace "ahead of 48.213 s" /
  "behind 186.920 s" (not "Best …"); 3BV/s best "PB 2.91"; "efficiency
  88.5%" in lower case; 3BV/s keeps "—" before any time.
- Tests asserting these strings updated.
- Context files that quote the changed strings
  (`records-board-code.md`, `app-shell-results.md`, `app-shell-themes.md`,
  `app-shell-2d.md`) updated.
