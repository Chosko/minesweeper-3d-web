# Task 79 — Watch replay on the results screen and from the library

Target: claude

## Goal
Put the replay viewer of feature `replay-playback` one step away: the
results screen gains *Watch replay* for the game it shows, and the replay
library's *Watch* actions open the viewer.

## Acceptance criteria
- The results screen shows *Watch replay* beside *Play again* for the game
  it shows, using the replay from the finished game's hand-off, so it plays
  even when the replay could not be saved; Back returns to the results
  screen.
- The library view's *Watch* on a replay, a best or a recent game opens the
  viewer with that replay id; Back returns to the Records screen on the same
  board.
- A game whose replay was dropped shows no *Watch replay*.
- Mouse, keyboard and controller operate the actions; Node tests cover the
  action's presence rules; Playwright watches a just-won 2D game from the
  results screen.
