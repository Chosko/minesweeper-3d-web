# Task 209 — Daily screen in the board-choice layout, listing every mode

Target: claude

## Goal
Recompose the Daily screen, for feature `shared-screen-layout`, as
J-Daily-xl/-l/-m/-p and J-Daily-states draw it, with the board choice
composition of task 166, and make it list every mode in menu order as
`game-shell` now states: Classic 2D and 3D with their state chip and board
line, Hexagon, Triangle and Surface as *Coming soon*; on the right the
selected mode's board preview, state, days in a row and code chip; a bottom
bar with *Watch replay* and *Play*.

## Acceptance criteria
- The screen is composed from catalogued components only, sharing task
  166's window, title and bottom bar.
- **Left:** "Today" with the date, the intro line, then one entry per mode
  in menu order — Classic 2D, Hexagon, Triangle, Surface, 3D. Classic 2D and
  3D show their state chip beside the name (*Not played*, *Won* with the
  time in the standard format of task 206, *Lost*) and their board line
  below; the others read *Coming soon* and cannot be played. Without WebGL 2
  the 3D entry is disabled with its reason.
- **Right:** for Classic 2D the closed Expert board with the marked start
  cell, for 3D the cube drawn through task 164's scene panel; the state with
  "Days in a row … · longest …"; the board code chip with Copy and Copy
  link. A coming-soon mode shows its colour badge and *Coming soon*.
- **Bottom bar:** the summary; *Watch replay* only for a won game whose
  replay the library kept; *Play*, disabled once today's try is used, for a
  coming-soon mode and for 3D without WebGL 2.
- **Phone** (J-Daily-p): one column, no title, no border and no preview,
  the code shown instead; fits the phone's height.
- The counted-attempt rules, pre-generation, the start-cell rules and the
  days-in-a-row figures behave as before.
- Every surviving element id, route, default focus and controller
  navigation target survives or moves with its owner;
  `tests/shell-daily.test.mjs` is updated first for the five mode entries,
  the coming-soon rows and *Play*'s disabled cases, and passes.
- No horizontal scroll at any supported window size; contrast checks pass
  under *Joyful tiles*.

## Decisions
- **Owner decision** (DESIGN-CHANGES §2.6, §4.4): Daily lists every mode in
  menu order; modes not built show *Coming soon*. Their rows exist so the
  layout is final; they have no daily boards yet (DESIGN-CHANGES §8).
- Task 206's time format is kept as built.
