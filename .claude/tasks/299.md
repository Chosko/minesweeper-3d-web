# Task 299 — Update documentation for feature `steam-cloud-saves`

Target: claude

## Goal
Feature `steam-cloud-saves` adds the main-process file service, the Steam
document storage and blob store, the quit flush, the Auto-Cloud
configuration, the machine prefs directory, document delete and list, the
pre-paint theme handed over by the host, and no browser storage on the Steam
build. The navigation layer and README need to describe where the desktop
build's saves live, what syncs and what stays on the machine.

## Acceptance criteria
- `.claude/context/desktop.md` describes the file service over the save
  directory and the machine prefs directory, its bridge operations
  (document read, write, delete, list and set aside; blob put, get, delete
  and list), and the theme id the main process reads and the preload hands
  over.
- `.claude/context/platform.md` names the Steam storage and blob store
  implementations, the flush hook, `clear()` over both directories and the
  machine-local document.
- `.claude/context/replay-library.md` notes the Steam blob store behind the
  library; `.claude/context/settings-appliers.md` (or the file covering
  `js/theme.js`) notes the pre-paint theme's handed-over id.
- `.claude/context/testing.md` lists the new tests; `.claude/context/INDEX.md`
  matches the files.
- `README.md` says where the desktop build keeps saves, that Steam Cloud
  syncs them and that machine settings stay on the machine.

## Decisions
- Replaces task 94, whose scope it carries, so the feature has one
  documentation task; it keeps 94's wait on task 93 because it documents the
  Auto-Cloud configuration.
