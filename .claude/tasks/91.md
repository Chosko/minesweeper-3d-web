# Task 91 — Main-process file service and the bridge's storage and blob operations

Target: claude

## Goal
Add the disk side of feature `steam-cloud-saves`: a file service in the
desktop host's main process, scoped to the save directory under the
user-data directory, reachable only through the bridge's storage and blob
operations, writing safely and keeping corrupt files aside.

## Acceptance criteria
- The save directory sits under the user-data directory and holds one file
  per document and a subdirectory per blob store, nothing else; window
  state and the crash log stay outside it.
- Writes go to a temporary file renamed over the old one; a crash
  mid-write never leaves a half-written file.
- Document and blob-store names are checked against a fixed pattern; no
  request reaches outside the save directory, and a bad name rejects with
  `invalid`.
- Operations: read, write and set-aside of a document file; put, get,
  delete and list of blobs in a named store. Set-aside renames the file
  with a dated suffix.
- A disk that cannot be written rejects with `failed`; nothing throws into
  the page.
- Node tests run the service on a temporary directory, including traversal
  attempts, an interrupted write and a read-only directory.
