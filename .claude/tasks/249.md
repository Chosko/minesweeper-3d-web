# Task 249 — Classic 2D board view on the grid geometry

Target: claude

## Goal
Part of feature `flat-grid-geometry`: move Classic 2D's board view onto the
geometry from task 248. The fit rule, the floor, the scale cap, the board
frame, the extent the game window hugs, scrolling and panning, the clipped
rounded viewport, the touch zoom, per-cell redraw, and the motion and ring
layers' tile positions all ask the geometry instead of square pitches.
Classic 2D looks and behaves exactly as it does now.

## Acceptance criteria
- `createBoardView` / `mountBoardView` take a geometry. Classic 2D passes
  the square geometry for its grid, and every caller (the game, the menu
  and Daily previews, the replay viewer) still mounts the same board.
- Layout, cell rectangles and centres, hit-testing (`cellAt`), the board
  point (`boardPoint`, in board units) and the touch zoom's anchor come from
  the geometry; nothing in the view computes a column or row from a pitch.
- The floor and the tile size at each board scale come from the geometry.
- A geometry and a graph built for different sizes are refused when the view
  is created (a `RangeError`), never at draw time.
- The shipped Classic 2D view, motion, cursor, touch and fidelity tests pass
  unchanged; screenshots of the Classic 2D boards are unchanged.
