# Task 93 — Steam Auto-Cloud configuration and quota fit check

Target: claude+human

## Goal
Turn on cloud sync for feature `steam-cloud-saves`: configure Steam
Auto-Cloud for the save directory, measure whether the replay library as
designed fits the quota the owner has already set in Steamworks (100 MB and
1000 files per user), and check that saves move between two machines.

## Acceptance criteria
- Real replay sizes are measured (largest 3D presets and long games
  included) and set against the quota: the bytes and the file count of the
  library's retention of unpinned replays plus pins plus the documents. The
  calculation is kept in `dev/measure-cloud-quota.mjs`, which reads the
  retention from the code rather than repeating it.
- `.claude/domain/features/steam-cloud-saves.md` records whether the library
  fits the quota in place of its open question, and
  `.claude/domain/features/replay-library.md` records whether Steam Cloud
  fits the library as designed in place of its Steam Cloud question. Nothing
  else in either document changes.
- The Auto-Cloud settings map the Windows root to the save directory,
  recursively; the game saves and loads unchanged.

## Decisions
- The quota is the owner's Steamworks setting, not this task's output: the
  task measures against it and never proposes a different one. If the
  library does not fit, the two documents record that it does not, and the
  report names it as a follow-up for the owner; the retention is not changed
  here.
- Settled here: whether the library fits the quota
  (`.claude/domain/features/steam-cloud-saves.md` § Open questions) and
  whether Steam Cloud fits the replay library
  (`.claude/domain/features/replay-library.md` § Open questions). Both
  documents are normally `/architect`'s; this task updates them for exactly
  this and for nothing else. The question whether machine-specific settings
  stay per machine stays open; the whole settings document syncs.

## Manual interventions

⚠ REQUIRES MANUAL INTERVENTION — pause implementation at these points and
walk the user through them in the Steamworks partner site and on two
Windows machines; wait for their confirmation and verify the outcome before
continuing:

1. Once the save directory's location is confirmed: the user enters the
   Auto-Cloud root (the save directory under the user-data directory) and
   the recursive pattern in the app's Steam Cloud settings, beside the
   quota already set, and publishes them. Verify by the user's screenshot
   or copy of the settings showing the root and pattern.
2. After publishing: the user plays and wins a game on machine A, quits,
   launches on machine B. Verify the record and the replay are present on
   B.
