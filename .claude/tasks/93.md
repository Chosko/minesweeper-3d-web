# Task 93 — Steam Auto-Cloud configuration and quota

Target: claude+human

## Goal
Turn on cloud sync for feature `steam-cloud-saves`: configure Steam
Auto-Cloud for the save directory with a byte and file-count quota sized by
measuring real replay sizes against the replay library's retention, and
check that saves move between two machines.

## Acceptance criteria
- Real replay sizes are measured (largest 3D presets and long games
  included) and the byte and file-count quotas are derived from 100 unpinned
  replays plus pins plus the documents, with headroom; the calculation is
  kept in `dev/measure-cloud-quota.mjs`.
- `.claude/domain/features/steam-cloud-saves.md` records the quota in place
  of that open question, and `.claude/domain/features/replay-library.md`
  records whether Steam Cloud fits the library as designed in place of its
  Steam Cloud question. Nothing else in either document changes.
- The Auto-Cloud settings map the Windows root to the save directory,
  recursively, with the quotas; the game saves and loads unchanged.

## Decisions
- Settled here: the quota (`.claude/domain/features/steam-cloud-saves.md`
  § Open questions) and whether Steam Cloud fits the replay library
  (`.claude/domain/features/replay-library.md` § Open questions). Both
  documents are normally `/architect`'s; this task updates them for exactly
  this and for nothing else. The question whether machine-specific settings
  stay per machine stays open; the whole settings document syncs.

## Manual interventions

⚠ REQUIRES MANUAL INTERVENTION — pause implementation at these points and
walk the user through them in the Steamworks partner site and on two
Windows machines; wait for their confirmation and verify the outcome before
continuing:

1. After the quota is computed: the user enters the Auto-Cloud root (the
   save directory under the user-data directory), the recursive pattern and
   both quotas in the app's Steam Cloud settings and publishes them. Verify
   by the user's screenshot or copy of the settings matching the computed
   values.
2. After publishing: the user plays and wins a game on machine A, quits,
   launches on machine B. Verify the record and the replay are present on
   B.
