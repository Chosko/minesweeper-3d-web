# Task 270 — Board codes and challenge links for Hexagon and Triangle

Target: claude

## Goal
Part of feature `flat-grid-modes`: Insert Board Code and `#board=` links
start a Hexagon or Triangle board on its coded start cell, through the
shell's code resolver, which tells a hexagon or triangle code apart by its
token and routes it to its mode's forced start.

## Acceptance criteria
- A hexagon or triangle code entered in its own mode's Insert Board Code, or
  opened as a `#board=` link from anywhere, starts that board on its start
  cell in its mode.
- A code of another mode entered in a board choice is refused with the
  other-mode hint, in each direction between Classic 2D, Hexagon, Triangle
  and 3D.
- A coded no-guess board that fails generation gets the failure offer with
  no replacement board.
- `#board=` links keep their place in history as for Classic 2D, and every
  shipped code keeps its meaning.
