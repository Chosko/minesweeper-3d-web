# Task 220 — Kit icon set and leading-icon slot

Target: claude

## Goal
The *Joyful tiles* canvas (Claude Design artifact
https://claude.ai/artifact/LeP32jxNxEnHLUtRwJ3FNC, page "Joyful tiles")
draws a leading icon in most buttons — back arrows, Play, Retry, Copy,
Records, Download and more — while every shipped button is text only
(only Restart, Pause and Swap carry one). Add the canvas's icon set and a
leading-icon slot to the kit so the screen tasks can apply them. This task
builds the kit part only; each screen task puts the icons on its own
buttons. Part of the canvas drift fixes; feature:
`shared-screen-layout`. Drift ids: the kit part of K5 (A4, B5, D15, E5,
F22, G4, H1-20, H1-25, H1-33, H2-2, H2-12).

## Acceptance criteria
- The kit has one icon source holding the canvas's stroke icons, copied
  path for path from the canvas (J-Components and the screens draw them):
  arrow-left (`M19 12H5M11 6l-6 6 6 6`, stroke 2.3), play, pause,
  restart/refresh, copy, link, chart, shuffle, grid, speaker, camera,
  download, upload, trash, mouse, hand, cube, pin, check, and the info /
  warning glyph the warn and err notes use. Icons draw in `currentColor`.
- A button can take a leading icon through the kit (markup helper and/or
  the kit catalogue): an 18px slot before the label with the button's
  10px gap, 14px on compact chip buttons (Copy, Copy link), 24px on lg
  buttons. An icon-only button (the Records replays trash action) has an
  accessible name.
- The kit catalogue and the gallery (`dev/components.html`) show the set
  and a button of each size with an icon, matching J-Components.
- Kit tests cover the slot sizes, `currentColor`, and that an icon is
  `aria-hidden` while the button keeps its label as its name.
- `.claude/context/app-shell-kit.md` (or `app-shell-kit-helpers.md`)
  documents the icon set and the slot.

## Decisions
- Canvas artboards to check against: J-Components (buttons with icons),
  plus any screen artboard for a given glyph's path.
- Kit part only; per-screen application is in the screen tasks (menu,
  Daily, board choices, pause, ready card, results, Records, replay,
  Settings, other surfaces), which depend on this task.
- The phone back button label "Back" with aria-label "Back to Main menu"
  is applied per screen in those tasks, not here.
- Depends on task 218 (button gap and md size).
