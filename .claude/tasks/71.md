# Task 71 — Replay store: blob interface, in-memory and IndexedDB implementations

Target: claude

## Goal
Add the replay store of feature `replay-library`: a platform-layer interface
for named binary blobs — put, get, delete, list — with an in-memory
implementation for tests and the browser implementation on IndexedDB,
selected at start-up the way `platform-storage`'s implementation is.

## Acceptance criteria
- The interface offers put, get, delete and list of named blobs, all
  asynchronous, and reports whether it persists this session.
- The browser implementation keeps each blob as one record in an IndexedDB
  object store; nothing goes to `localStorage`.
- Start-up selection mirrors `platform-storage`'s: when IndexedDB is
  unavailable or refuses to open, the in-memory implementation is used and
  the store reports that it does not persist.
- Node tests cover the interface on the in-memory implementation; a
  Playwright check round-trips a blob through IndexedDB.
