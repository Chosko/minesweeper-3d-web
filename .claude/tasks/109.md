# Task 109 — Steam rank panel on the results screen

Target: claude

## Goal
Implement feature `results-steam-rank`: a non-interactive rank panel on the
results screen in the Steam build, for a won game on a catalogue board,
showing the global rank with its move and the friends rank after an
improving win, the standing "your best" ranks otherwise, and offline
wording when Steam does not answer in about 5 seconds.

## Acceptance criteria
- The panel sits below the three-best comparison only when the
  leaderboards capability is present, the game was won and its board has a
  leaderboard; otherwise the view keeps its existing layout. It never takes
  focus or moves the default focus off *Play again*; text changes are
  announced politely.
- A resolver started by the results flow follows the summary's submission
  state: submitted → global rank with its move (#120 → #87, or "new entry")
  and friends rank from own standing; not eligible, already beaten or
  rejected by verification → own standing as "your best"; pending → keeps
  waiting.
- "ranking…" shows for up to about 5 seconds, then "Will be ranked when you
  are back online" for a pending win or "Rank unavailable offline"
  otherwise; a later answer still fills the panel while the screen is
  open. Leaving the screen stops the resolver and drops its subscription.
- A rejected query ends in the offline wording; the rest of the results
  screen is never blocked or delayed. Works the same for Classic 2D and 3D
  results.
- No route to the leaderboard screen is added; the feature document leaves
  it open.
- Node tests drive the resolver through every state and the timeout with a
  fake leaderboards module and a fake clock; Playwright checks the web
  build shows no panel.
