# Task 240 — Settings screen to the canvas

Target: claude

## Goal
Bring the Settings screen in line with the *Joyful tiles* canvas (Claude
Design artifact https://claude.ai/artifact/LeP32jxNxEnHLUtRwJ3FNC, page
"Joyful tiles"). A design review found the frame, body spacing, column
arrangement, setting rows, theme list, Data panel and phone layout drift,
and an extra Controls button the canvas does not draw. Part of the canvas
drift fixes; intended feature: `shared-screen-layout` (the theme list
belongs to `theme-system`). Drift ids: H2-24, H2-25, H2-26, H2-27, H2-30,
H2-31, H2-33, H2-36, the Settings part of K33. (Sliders and switches
H2-28/29 are task 219's; bindings H2-32 task 233's; reset confirmation
and failure H2-34/35 task 221's; back button "Back" on the phone, H2-4,
applies here.)

## Acceptance criteria
- **Frame (H2-24).** At 140/66, 1640×940 at xl, everything fitting without
  body scroll (with 3D bindings shown); l 32/24, 1302×712; m 20/16,
  984×728.
- **Spacing (H2-25).** Body padding and column gap 24 (xl), 18 (l), 14
  (m); stack gap equal to the column gap; phone padding 14px 14px 30px,
  gap 16.
- **Columns (H2-26).** Two independent stacks at l and m — left: Controls,
  Graphics, Audio; right: Theme, Data, Bindings — with no shared grid rows.
- **Rows (H2-27).** Each setting row padding 10px 0 with a 1px --color-line
  border-top (including under the section label); name 16px/700; the "3D"
  note 13px muted.
- **Theme list (H2-31).** Separate raised theme cards: radius 14, padding
  10px 12px, gap 10, `inset 0 -2px` edge-inset plus `0 3px` edge. Selected
  card blue #3563d8 with blue-on text, 4px blue-edge drop and highlight,
  and a check icon at the right. Name 17px/800. Swatch: 5 stripes of
  16×28 (80×28), radius 8, a 2px surface ring, from ground, head,
  accent-fill, blue and teal (`SWATCH_TOKENS`).
- **Data panel (H2-33).** Export line 15px muted: "Save every recorded game
  as a spreadsheet, or the history and the list of kept replays as one
  file."; exports are sm (15px, padding 7px 13px, 38 tall) with download
  icons; the reset line 15px ink; "Reset all data…" md, auto width, with a
  trash icon; no "Nothing to export yet" line.
- **Phone (H2-36, H2-4).** Export buttons stack, each sm with a download
  icon; the Device choice keeps its own row with wrapping options; the
  head's back button reads "Back" (aria-label "Back to Main menu"); every
  row rule above applies at phone size.
- **Controls action (H2-30).** Remove the extra full-width "Controls"
  button (`CONTROLS_ACTION`, `#set-controls`) if it duplicates the
  bindings list; otherwise keep it and the closing report asks the design
  side to draw it.
- Settings tests updated (with task 215's multi-theme tests passing);
  renders match the artboards.
- `.claude/context/settings-page.md` reflects the screen.
