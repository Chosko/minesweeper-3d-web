# Task 244 — Update documentation for feature `shared-screen-layout`

Target: claude

## Goal
Feature `shared-screen-layout` brought the kit and every non-game screen in
line with the *Joyful tiles* canvas: the quiet and danger buttons and the
latched toggles, the icon set and leading-icon slot, the switch row, the
slider fill and the invalid field, the confirm box, the warn and err notes,
the plain stat tile, the muted panel, the ruled table, the pager and the
code chip, the controls list, the frame's compact and touch steps, the
white action foot, the message and status cards and the scrims without
blur; and the menu, Daily, board choice, pause, 3D ready card, results,
Records, replay viewer, Settings and other surfaces recomposed from them,
with the canvas's copy. Each task updated the context file of its own
area; this task brings the documentation layer as a whole up to date with
what shipped.

## Acceptance criteria
- The context files under Files describe the shipped kit parts, screens and
  copy, with no passage still describing the replaced look (white panels
  for confirmations, the blurred scrim, the labelled replay overlay, the
  long controls rows, the blue latched toggle).
- `.claude/context/testing.md` describes the changed and added tests;
  `.claude/context/INDEX.md` rows say what each file covers now, with
  `Last updated` advanced.
- `.claude/domain/features/shared-screen-layout.md` records the details
  tasks 218–242 settled that hold at ship time (the catalogued names of the
  icon slot, the controls list, the size steps and the white action foot,
  and the Settings Controls action's outcome). Nothing else in it changes.
- The documentation states no value the code holds (rule 10 of CLAUDE.md
  § Editing Discipline).

## Decisions
- **One documentation task for the feature's canvas drift fixes** — it
  covers every task linked to the feature in this planning pass, task 235
  (whose HUD parts touch `in-game-layout`) included; task 240's theme list
  part stays with this feature's tasks.
