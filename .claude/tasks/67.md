# Task 67 — Classic 2D capture and the replay on the mode contract

Target: claude

## Goal
Record every Classic 2D game for feature `replay-recording`: the 2D session
creates a recorder, feeds it each action and a movement sampler of the
pointer and the keyboard and controller cursor, and the game shell's mode
contract carries the sealed replay beside the summary.

## Acceptance criteria
- The Classic 2D session creates a recorder when the board opens, feeds it
  at the point it calls the engine, and discards it with the session.
- The 2D sampler records the pointer in board coordinates (cell units,
  quantised) about 20 times a second, including off the board, and the
  cursor's cell whenever it moves, only while the game is started, unpaused
  and unfinished; paused time is absent.
- The mode contract becomes `game finished(summary, replay)` and `game
  abandoned(summary, replay)`; a game left before its first click records
  and reports nothing. The 3D adapter passes no replay until task 68.
- Node tests cover the sampler and a recorded 2D game sealed through the
  session with a fake clock.
