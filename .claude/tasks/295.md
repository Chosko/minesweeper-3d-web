# Task 295 — Desktop window size after a theme switch and the failed-board card over the pause card

Target: claude

## Goal
For feature `steam-desktop-host`: two cases the windowed desktop window's
sizing leaves unchecked. First, the window's reported height includes the
edge frame's drop edge, which `dropEdgeOf` (`js/platform/window-actions.js`)
reads from the frame's computed `box-shadow`; a theme switch can change that
drop edge without resizing the frame, so the window only picks up the new
drop edge at the next screen change. Second, a flat game's board can fail
while it is paused, so the failed-board offer card (`#c2d-status`, marked
`data-window-inside`) can show over the pause card (`#pause`, marked
`data-window-over`) while the window is the pause card alone; whether the
offer card then sits inside the window has never been checked.

## Acceptance criteria
- Windowed, a theme switch whose edge frame has a different drop edge
  re-measures the window at once: the reported size carries the new drop
  edge without waiting for a screen change, and a switch that leaves the
  drop edge and the frame unchanged reports nothing new.
- Windowed, a flat game whose board fails while paused shows the
  failed-board offer card wholly inside the window that the pause card sizes,
  and the window keeps the pause card's size; if it does not, the card is
  placed or bounded so that it does.
- Fast tests cover the theme-switch re-measure (a fake frame whose computed
  `box-shadow` changes) and the offer card's placement over the pause card;
  a browser test only if the placement needs a real layout, per
  `.claude/context/testing-browser.md`.

## Decisions
- **One task for both cases**: each is a small check-and-fix on the same
  window-sizing code; split them if implementation shows otherwise.
- Settled here: `steam-desktop-host.md` § The desktop window says the page
  reports the window's size on every screen change and every change of the
  frame's size, and that the board status card stays inside the game window;
  this task holds both true across a theme switch and while the pause card
  sizes the window. The document needs no change.
