# Task 258 — Triangle graph provider and the `tri` generation description

Target: claude

## Goal
Part of feature `triangle-grid`: add the triangle cell-graph provider beside
the square-grid provider, and the `tri` description that board generation,
the generation worker and the marked start cell accept. A board of W × H is
H rows of W triangles; the tile at column c, row r points up when c + r is
even. A tile's neighbours are every tile sharing a side or a corner, 12 in
the interior. The rules engine plays on it unchanged, numbers 0-12 included.

## Acceptance criteria
- The provider takes width and height and returns the immutable cell graph
  with the square provider's index (column + width × row) and column-row
  helpers, plus an orientation query (up or down) per cell. An interior
  tile's 12 neighbours are 5 on the side of its base, 3 on the side of its
  tip and 2 on each side in its own row. Every neighbour list is in
  ascending index order. Interior, edge and corner neighbourhoods of both
  orientations are pinned by tests. An impossible size throws a
  `RangeError`.
- The generator, placer, logic-only solver and no-guess loop run over a
  `{ kind: 'tri', width, height }` description with the same attempt budget
  and no generator version change; worker and Node give the same board for
  the same request, seed and version.
- The solver's node budget treats an oversized frontier group as
  unconstrained, so it may lose deductions but never makes a wrong one; a
  test pins that on a 12-neighbour board.
- The marked start cell of a `tri` description is the centre column and row.
- The reference profile's reveal, flag, chord, safe first click, 3BV and
  click counting are tested on a small triangle board, a 12 included.
- The no-guess generation time on Expert (41 × 17, 103 mines) is measured
  and reported, with a follow-up for `board-generation` if it misses the
  attempt budget's timing; the budget is not changed here.

## Decisions
- Settles the feature document's open question on Expert no-guess timing by
  measuring it; a budget change is not this task's.
