# Task 164 — 3D scene drawn into a screen's scene panel

Target: claude

## Goal
Give the 3D renderer a target rectangle, for feature `shared-screen-layout`:
while a screen with a scene panel shows, the shell hands the renderer the
panel's rectangle and the scene draws only there, the panel's frame and
corners drawn by the theme stylesheet over it; on every other screen, in a 3D
game and in the 3D replay viewer, it draws full-window as today.

## Acceptance criteria
- The renderer takes a target rectangle in CSS pixels (or `null` for the full
  window) and sets its viewport, scissor and camera aspect to it; nothing is
  drawn outside it, and a resize or pixel-ratio change re-applies it.
- The shell sets the rectangle from the shown screen's scene panel element on
  screen change, on window resize and when the panel's box changes (a
  `ResizeObserver`), and clears it on leaving that screen.
- The 3D game, the 3D replay viewer and their camera, picking and HUD are
  unchanged: picking in a 3D game still maps the full window.
- Render-on-demand still draws a frame only when something changed.
- A browser test shows a page with a scene panel: pixels outside the panel are
  the page's, inside are the scene's, and a resize moves the scene with the
  panel.
- Until task 165 places the panel on the menu, no screen has one, so nothing
  visible changes.

## Decisions
- **Settled design detail** (`.claude/domain/features/shared-screen-layout.md`
  § Architecture, *Scene panel*): the `ResizeObserver` tracking. The feature
  document is not edited here; task 173 records what holds at ship time.
