# Task 262 — Hexagon and triangle outlines in the tile recipe

Target: claude

## Goal
Part of feature `hex-tri-board-art`: the shared tile recipe `js/tile-art.js`
draws each drawing style (`flat`, `bevel`) in an outline (square, hexagon,
triangle up, triangle down) along with size, depth and palette, and draws
each glyph in a glyph box. The square outline draws exactly what it draws
today, so neither the 3D atlas nor Classic 2D tiles change.

## Acceptance criteria
- `drawFace` takes an outline and draws the closed, sunk and revealed faces
  clipped to it at any size and depth, with the top band and bottom edge
  inside the outline. A bevel's sloped sides follow the outline's edges,
  each shaded by the way it faces.
- The number, flag, mine, wrong-flag cross and start-cell ring glyphs draw
  in a given glyph box: a hexagon's box is its size across the flats, a
  triangle's is 0.55 of its side, centred on its centroid.
- Every colour and parameter is an argument; the recipe holds no literal
  colour.
- The square outline's pixels, for both styles and every face and depth, are
  unchanged (the shipped tile-art tests and the 3D atlas tests pass
  unchanged), and new tests cover each outline and style.
