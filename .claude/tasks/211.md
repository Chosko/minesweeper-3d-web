# Task 211 — Toasts, fatal card, no-JavaScript notice and 404 page in the shared layout

Target: claude

## Goal
Restyle the remaining messages of the game, for feature
`shared-screen-layout`, as J-Other-xl/-l/-m/-p and J-Other-states draw them:
the status toasts (polite, transient, bottom centre), the fatal "Cannot start
Minesweeper 3D" card with Reload, the no-JavaScript notice and the 404 page,
on the page backdrop with catalogued components.

## Acceptance criteria
- Toasts, the fatal card and the no-JavaScript notice are composed from
  catalogued components; each keeps its text, its live-region politeness and
  its behaviour (the fatal card's Reload, the toast's timing).
- `404.html` shows "Page not found." and *Go to Minesweeper 3D* on the
  *Joyful tiles* backdrop, as J-Other draws it, with no script and no
  remote resource; it loads the base and theme stylesheets and the theme's
  self-hosted fonts.
- The no-JavaScript notice renders styled with JavaScript disabled.
- Existing toast, fatal-card and no-WebGL tests are updated only where they
  assert the old arrangement, and pass; a test checks `404.html` references
  only local files.
- Phone sizes per J-Other-p; contrast checks pass under *Joyful tiles*.

## Decisions
- **Gap closed** — the canvas draws these surfaces (J-Other-*) and no task
  built them in the shared layout; they are "as delivered" screens of the
  design (DESIGN-CHANGES §4). The placeholder page and the confirmations on
  the same artboards are task 168's.
- **No theme switch on the 404 page and the no-JavaScript notice** — neither
  runs the theme applier; both show *Joyful tiles*, the default theme.
