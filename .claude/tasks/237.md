# Task 237 — Results screen to the canvas

Target: claude

## Goal
Bring the results screen (2D and over 3D) in line with the *Joyful tiles*
canvas (Claude Design artifact
https://claude.ai/artifact/LeP32jxNxEnHLUtRwJ3FNC, page "Joyful tiles").
A design review found the head, rank chip, card size, progress bar,
details, buttons and phone layout drift, a first-use toast covers the
card, and the neutral loss header is not built. Part of the canvas drift
fixes; feature: `shared-screen-layout`. Drift ids: H1-1, H1-3,
H1-4, H1-5, H1-8, H1-14, H1-15 (use), H1-16, H1-18 (use), H1-19 (use),
H1-20, H1-22, P3 (H1-23).

## Acceptance criteria
- **Head (H1-1).** Padding 22px 28px (18px on phone); title 40px heavy
  (32px on phone); the trophy in a 56×56 white tile, radius 16, `0 4px 0`
  head-edge drop; board line 16px/700.
- **Loss header (P3).** After a loss the head is the canvas's neutral
  header (not the win look).
- **Rank (H1-3).** 2D rank chip 14px, padding 6px 12px, white. 3D: the
  rank inline at the end of the board line ("… · #9 of 42 wins on this
  board"), not on its own line.
- **Card (H1-4, H1-5).** Width 1040 (xl), 1000 (l), 960 (m), centred;
  radius 22, `0 8px 0` head-edge drop.
- **Toast (H1-8).** No first-use toast draws over the results card (defer
  it until results close, or suppress it while results show).
- **Progress (H1-14).** The 3BV solved bar: 10px high, radius 6, track
  --color-line #f3dca0, fill --color-teal-edge #2a9488 (not the native
  `<progress>` look).
- **Details (H1-15).** Task 222's table: label 15px/800 ink sentence case,
  min-width 110; value JetBrains Mono 14px; a full-width 1px line rule per
  row; on phones label over value.
- **Tiles, code, foot.** Task 222's plain stat tiles (with the yellow new
  best), the code row with the "BOARD CODE" label left and the compact
  chip right (label above on phones), and task 223's white action foot
  (padding 16px 28px 20px; 14px 22px 18px at l and m).
- **Buttons (H1-20).** Every action has its icon: arrow-left Main menu,
  grid Watch replay, chart Records, play Play again, Watch best; secondary
  md sizes from task 218.
- **Phone (H1-22).** The card sits at 12px left/right/top insets and the
  page scrolls; the action bar is in flow at the card's end; body padding
  16px; Play again and Main menu show no key hints on touch.
- **Detail copy (H1-16).** Clicks "128 · left 104 · right 24 · chords 0 ·
  wasted 0"; next target "beat 47.380 s · streak 8"; loss streak "ended at
  5 · longest 7"; loss win rate "64% · completed games 71%" (no longest
  streak). When Swap clicks is on, keep "reveal / flag" instead of
  "left / right".
- Results tests updated; renders match the artboards.
- `.claude/context/app-shell-results.md` reflects the screen.
