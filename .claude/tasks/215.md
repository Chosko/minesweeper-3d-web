# Task 215 — Settings page tests hold with more than one shipped theme

Target: claude

## Goal
`tests/settings-page.test.mjs` asserts the theme setting's generated
markup as if *Joyful tiles* were the only theme in the registry — a literal
single row, a single checked option — so registering the first real second
theme in `js/themes/registry.js` would fail these tests although the page
is right. The tests are reworked to state what they mean for any number of
registered themes, so adding a theme to `THEMES` is a change the settings
page's tests accept without edits.

## Acceptance criteria
- Every assertion in `tests/settings-page.test.mjs` about the theme list,
  its rows, its swatches, its checked option and its section is written
  over `THEMES` (one row per entry, in registry order, each with its name,
  its swatch and its `data-value`; exactly one row checked, the active
  theme's) or over the default theme by `DEFAULT_THEME_ID`, never over a
  literal count of one or a literal list of ids.
- Proof: the file passes as it stands, and the same theme-list assertions
  pass against a list of two themes — *Joyful tiles* and the fixture theme
  `tests/fixtures/themes/fixture-theme.js` — fed to the page's theme-list
  generator through a list parameter it takes (defaulting to `THEMES`) or a
  test seam it already has. `THEMES` stays frozen and unmutated, and no
  shipped theme is added by this task.
- Any other fast-tier test file found asserting a single shipped theme
  (a grep over `tests/` for literal `joyful-tiles` counts and one-row
  assumptions) is fixed the same way, or named in the closing report when
  its single-theme assertion is deliberate (for example *Joyful tiles*'
  own token values).
- The settings page's code changes only for that list parameter, or for a
  real one-theme assumption found in it; such a fix carries its own test.

## Decisions
- **Split from the font-unload fix**: the two block the same milestone
  event but touch disjoint code (the settings page's tests against the
  theme applier's font loading) and are verified differently, so each is
  its own task and commit.
