# Task 278 — Menu routes, last mode played and Daily for Hexagon and Triangle

Target: claude

## Goal
Part of feature `flat-grid-menu-entries`: choosing Hexagon or Triangle opens
its board choice through the mode host because both modes are registered
(task 268), the menu's opening selection follows the last mode played
whichever of the five it is, and the Daily screen's list keeps one entry per
menu mode with both registered modes in it. Their daily boards, which make
those rows playable, are task 280's.

## Acceptance criteria
- `open('hexagon')` and `open('triangle')` take the mode route to the
  mode's board choice, opened on its last board so Enter then Play replays
  it. Surface, not registered, stays on *Coming soon*; an unavailable entry
  still opens nothing.
- The last-mode record takes `hexagon` and `triangle`. The menu's opening
  selection follows it; no tile shows a Last played chip (task 283). A stored value naming an
  unregistered mode reads as none.
- The Daily list keeps one entry per menu mode in menu order; a mode with no
  daily board reads *Coming soon* and is never playable, whether or not it
  is registered, so Hexagon and Triangle read *Coming soon* until task 280
  adds their daily boards.
- Menu, returning and Daily tests pin each of these.

## Decisions
- **No Last played chip** (design changelog 2026-10-23, "Joyful main menu:
  no Last played chip"): only the opening selection follows the last mode.
