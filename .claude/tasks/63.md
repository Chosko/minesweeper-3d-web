# Task 63 — Per-mode counters, mode-filtered board listing and the records format step

Target: claude

## Goal
Extend `personal-records` for feature `3d-game-records`: 3D boards kept in
the same bests, history, win rate and streaks, overall counters per mode so
no figure combines Classic 2D and 3D, the boards-played query by mode, and
the records format version step that carries m1 records over unchanged.

## Acceptance criteria
- Recording a summary updates its board's counters and its own mode's
  overall counters only; a 3D loss, or a 3D game abandoned after its first
  reveal, never moves a 2D streak or win rate.
- Bests per 3D board follow the m1 rules (three bests from won games,
  strictly better replaces, a tie keeps the earlier holder) and every record
  returns the comparison against the bests that stood before it.
- The boards-played query takes a mode; for 3D it lists the six presets in
  the order double layer Beginner, Intermediate, Expert, then cube Beginner,
  Intermediate, Expert, each with and without no-guess, then custom 3D
  boards by last played. A mode's overall counters are queryable; no query
  spans modes.
- The records document's format version steps up once: loading an m1
  document carries every board and the Classic 2D overall counters over
  unchanged and starts the 3D overall counters at zero; rebuilding from the
  history document rebuilds the per-mode counters.
- A refused newer version, and an older build meeting the stepped-up
  format, behave as `personal-records` already specifies.
- Node tests cover mode separation, the listing order, the m1 upgrade, the
  rebuild and the abandoned 3D game.
