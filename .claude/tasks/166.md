# Task 166 — Classic 2D board choice screen with its records panel

Target: claude

## Goal
Recompose the Classic 2D board choice screen, for feature
`shared-screen-layout`, from the S3D-Setup artboard: inside the screen frame,
the board options with each board's best time, the no-guess switch, the Play
action with its key hint, and beside them the chosen board's records panel —
bests (time, 3BV/s, efficiency, with when each was set), wins, win rate and
streak, recent games, and a chart of its last 30 times — read from the records
store. Custom keeps its size fields, revealed when Custom is chosen.

## Acceptance criteria
- The screen is built from catalogued components only (screen frame, board
  option, section label, key hint, stat tile, list row).
- Each board option shows its name, size line and best time (or none);
  selecting one updates the records panel at once.
- The records panel reads the records store through its existing read
  interface and change notification and holds no records of its own; the chart
  reuses the Records screen's chart component over the board's last 30 games'
  times; a board with no games shows an empty state.
- Custom shows its size fields only while chosen; validation, the last board
  choice document and no-guess behave as before.
- Every element id, route, default focus and controller navigation target
  survives; existing board choice and returning tests pass, updated only where
  they assert the old arrangement.
- No horizontal scroll at 1024 px wide; contrast checks pass under *Joyful
  tiles*.

## Decisions
- **Settled design detail** (`.claude/domain/features/shared-screen-layout.md`
  § Scope, *Board choice screens*): the chart reuses `history-chart.js` with
  the time series. The feature document is not edited here; task 173 records
  what holds at ship time.
