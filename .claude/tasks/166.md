# Task 166 — Classic 2D board choice screen with its bests, Insert Board Code and Custom Random

Target: claude

## Goal
Recompose the Classic 2D board choice screen, for feature
`shared-screen-layout`, as J-C2D-xl/-l/-m/-p and J-C2D-states draw it: the
game's title above a window sized to its content; on the left the board
options, Custom and, after a divider, *Insert Board Code*; on the right what
the selection needs — the no-guess switch and the board's three bests, the
Custom form with its new *Random* fill, or only the code field; a bottom bar
with the selection's summary, *Records* and *Play*. The code is played with
*Play*, which replaces the *Play this board* button (`classic-2d-square-play`).

## Acceptance criteria
- The screen is built from catalogued components only (screen frame with
  its bottom bar, board option, section label, switch, number fields, key
  hint, stat tile, chip).
- **Window.** The game title on top as on the menu; the window sized to its
  content (its width per artboard at each desktop size), centred vertically
  on the page and pushed below the title only when the page is too short for
  both. At the smaller desktop sizes the option rows use their denser size
  so the window fits a 768 px-high page.
- **Left.** Section label *Board*; Beginner, Intermediate, Expert, Custom;
  a divider; *Insert Board Code* ("Play the exact board a code describes",
  no icon). Each preset shows name, size line and mine density, and the Last
  played chip beside the name. The chosen board is the board option's chosen
  state; hover and focus its selected state.
- **Right, a preset selected:** *Board settings* with the no-guess switch,
  then "<board> · <no-guess> · your bests" with three tiles only — Time,
  3BV/s, Efficiency — each with its date, or a dash and "no best yet". No
  wins, win rate, streak, charts, recent games or Top 5. Every part follows
  the switch.
- **Right, Custom:** the no-guess switch (with the density hint when it
  applies), the form — Width, Height, Mines, the info line, *Random*, the
  refusal line — then the bests for that size. *Random* fills width, height
  and mines with a valid random board, as the 3D form's Random does, and the
  fields' validation shows on what it fills.
- **Right, Insert Board Code:** only the code field and its one-line
  feedback — empty: "Paste a board code to play that exact board."; valid:
  what the code describes; refused: the reason; a 3D code: the hint naming
  the 3D board choice. No bests, no switch, no *Play this board*.
- **Bottom bar:** the selected board summarised on the left; *Records*
  (opens the Records screen on the selected board and switch, Back
  returning here) and *Play* with its Enter hint on the right. *Play* always
  reads "Play"; it starts the selected preset, the custom size, or the
  code's challenge, and is disabled on a refused custom size and on an
  empty or refused code.
- **Phone** (J-C2D-p): one column, full-bleed, no window border and no game
  title — the options and *Insert Board Code*, then the switch, the Custom
  form or the code field; no bests; *Records* and *Play* pinned at the
  bottom.
- The bests read the records store through its existing read interface and
  change notification and hold no records of their own.
- Custom validation, the last board choice document, the challenge rules
  and no-guess behave as before; the opening selection is the last board
  played.
- Every surviving element id, route, default focus and controller
  navigation target survives or moves with its owner; board choice, code
  and returning tests are updated first (the code played by *Play*,
  *Random*, the removed records parts) and pass.
- No horizontal scroll at any supported window size; contrast checks pass
  under *Joyful tiles*.

## Decisions
- **Owner decisions** (DESIGN-CHANGES §2.5, §2.7, §4.2): the board code is
  a fifth option played with *Play*; Custom gains *Random*; the right side
  shows settings and three bests only. These reverse the records panel this
  task first carried (charts, recent games, Top 5, wins and streak) and its
  owner answers on Top 5 and chart ranges, which no longer apply.
- **Moving the board code to the main menu** was discussed and not adopted
  (DESIGN-CHANGES §2.5).
- **The canvas is the source** (owner, DESIGN-CHANGES §1): built from the
  J-C2D artboards, not the earlier S3D-Setup.
- **Settled design detail** (`.claude/domain/features/shared-screen-layout.md`
  § Scope, *Board choice screens*): the summary line's wording. The feature
  document is not edited here; task 173 records what holds at ship time.
