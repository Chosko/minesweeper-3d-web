# Task 98 — Local leaderboards stand-in for the web build

Target: claude

## Goal
Give the web build the local half of feature `steam-leaderboards`: the same
interface over the player's own won games on a board, from
`personal-records`' history, ranked by time, selected by the platform layer
when the bridge is absent.

## Acceptance criteria
- `entries(board, scope, range)` returns, for every scope, the player's own
  wins on that catalogue board ranked by time, each named as the player and
  linked to its replay when the replay library still keeps it.
- `standing(board)` returns the player's best time and its local rank;
  `submit` is a no-op that reports not eligible for Steam.
- `replayFor(entry)` returns the library's replay or "no replay attached".
- The platform layer selects the stand-in when no bridge is present and the
  Steam implementation (task 97) when it is; callers use one module.
- Node tests cover ranking, replay linking and selection with a fake
  history and library.
