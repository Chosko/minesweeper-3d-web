# Task 256 — Hexagon boards, limits, identity and board-code token

Target: claude

## Goal
Part of feature `hexagon-grid`: set the Hexagon mode's standard boards and
custom limits, how a hexagon board is identified in the records, and how it
is spelled in a board code, so a mode can play one (`flat-grid-modes`).

## Acceptance criteria
- Standard boards, as drawn on the Hexagon board sheet: Beginner 9 × 9 with
  13 mines, Intermediate 16 × 16 with 50, Expert 30 × 16 with 100.
- Custom boards: 1 to 100 a side; mines from 1 to Classic 2D's cap for the
  same cell count, at most cells − 1. A 1 × 1 board is refused on the mines
  field. Validating a custom choice gives the field and reason of a refusal,
  in Classic 2D's shape; no-guess is never refused up front.
- The board identity's hexagon form: mode `hexagon`, grid `hex`, width,
  height, mines, no-guess. Beginner, Intermediate and Expert are recognised
  from exact size and mine count on the `hex` grid. The board-key format
  version does not change.
- Board codes: a hexagon board encodes as `H` before the 2D token (`HB`,
  `HI`, `HE`, `H<w>X<h>M<mines>`, then `N` when no-guess). Parsing checks
  the size against these limits and builds the `hex` graph. Every existing
  code keeps its meaning.
- A hexagon code checked against another mode's board choice is refused as
  another mode's code, the way a 3D code is.
- The Hexagon Expert no-guess checks use the standard Expert board. In
  `tests/generation-noguess.test.mjs`, the Hexagon Expert test expects every
  seed it runs to be accepted and to clear from the start cell, with no
  miss; the worker-and-Node parity test runs Expert no-guess at the standard
  count and keeps a no-guess miss for the failure result's parity on a board
  that misses by construction. `dev/measure-noguess-hex.mjs` measures Expert
  at the standard count, and every seed it measures meets the attempt
  budget.

## Decisions
- **Hexagon Expert has 100 mines (user decision, 2026-10-21):** at 123,
  no-guess generation finds a board within the attempt budget only about 1
  time in 10, and the Hexagon daily board is Expert with no-guess. The budget
  stays unchanged; the density rule holds for Beginner and Intermediate.
- **The values live in a new `js/hexagon/board-setup.js`**, mirroring
  `js/classic2d/board-setup.js` and `js/mode3d/board-choice.js`, so the board
  choice (task 268) and the board-code parser both import them.
