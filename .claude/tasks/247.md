# Task 247 — Update documentation for feature `theme-system`

Target: claude

## Goal
Feature `theme-system` brought the component gallery in line with the
*Joyful tiles* canvas's components artboard: no overlapping parts, every
part the artboard draws shown, the Settings theme list (the raised theme
cards with their striped swatches) included, the parts the artboard does
not draw kept as kit coverage, and the kit catalogue listing every part
the gallery shows. Task 243 updated the gallery passage of its own context
file; this task brings the documentation layer as a whole up to date with
what shipped.

## Acceptance criteria
- `.claude/context/app-shell-kit.md`, `app-shell-themes.md` and
  `settings-page.md` describe the gallery's coverage and the theme list as
  shipped.
- `.claude/context/testing.md` describes the changed and added gallery
  tests; `.claude/context/INDEX.md` rows say what each file covers now,
  with `Last updated` advanced.
- `.claude/domain/features/theme-system.md` records the details task 243
  settled that hold at ship time. Nothing else in it changes.
- The documentation states no value the code holds (rule 10 of CLAUDE.md
  § Editing Discipline).

## Decisions
- **The theme cards themselves are built by task 240** under
  `shared-screen-layout`, whose documentation task 244 covers the Settings
  screen; this task documents the theme list as a gallery part and as
  `theme-system`'s list.
