# Task 114 — Update documentation for feature `input-rebinding`

Target: claude

## Goal
Feature `input-rebinding` makes keys, mouse buttons and controller buttons
rebindable in Settings and routes both modes' input through a bindings
resolver. The navigation layer and README describe fixed bindings and need
to match.

## Acceptance criteria
- `.claude/context/input.md` describes the resolver and how each input
  layer translates physical inputs to actions and logical buttons.
- `.claude/context/app-shell.md` describes the rebinding panels on the
  Settings page and the help reading the current bindings.
- `.claude/context/testing.md` lists the new tests; `.claude/context/INDEX.md`
  stays accurate.
- `README.md`'s Controls section says the listed inputs are the defaults and
  can be changed in Settings.
