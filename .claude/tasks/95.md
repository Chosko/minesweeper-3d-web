# Task 95 — Leaderboard catalogue, eligibility and score details

Target: claude

## Goal
Add the DOM-free core of feature `steam-leaderboards`: the catalogue mapping
a board identity to its stable Steam leaderboard name — 18 boards, Classic
2D Beginner, Intermediate and Expert and the six 3D double-layer and cube
presets, each with no-guess on and off — the eligibility rule, and the
score and details encoding.

## Acceptance criteria
- `leaderboardFor(board)` returns the stable name for each of the 18
  catalogue boards and none for custom boards, the flat 3D presets and any
  other board; names are derived from mode, standard size and no-guess and
  pinned by a test so they never change.
- Score is the elapsed time in integer milliseconds.
- Details are an integer array: details format version, replay format
  version, rules version, 3BV, 3BV solved, and clicks by kind; a decoder
  returns them, and 3BV/s and efficiency derived from decoded details match
  `game-summary`'s derivations to the digit.
- `eligible(summary, replay, knownBest)` is true only for a won game on a
  catalogue board with a sealed replay that beats the known Steam best (or
  with no known best).
- Node tests cover every catalogue board, the excluded boards, details
  round-trips and each eligibility branch.
