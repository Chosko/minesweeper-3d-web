# Task 102 — Steamworks achievement definitions, threshold calibration and overlay check

Target: claude+human

## Goal
Finish feature `steam-achievements` on Steam: calibrate the speed and
efficiency thresholds against real play, author the display names,
descriptions and icons, define the achievements in the Steamworks app
settings with the catalogue's API names, and confirm an unlock shows in
Steam's overlay.

## Acceptance criteria
- The thresholds are calibrated from real play data (the player's records
  and any reference times the user supplies) and set in the catalogue's
  constants.
- `.claude/domain/features/steam-achievements.md` records the thresholds
  and the display text in place of those two open questions. Nothing else
  in the document changes.
- Every catalogue API name exists in the published Steamworks settings.
- A win on the private build unlocks its achievement and Steam's overlay
  shows the notification.
