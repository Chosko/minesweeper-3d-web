# Task 48 — Records view: board picker and figures

Target: claude

## Goal
Build the main view of feature `records-screen`, reached from the main menu
and from the results screen: a board picker over the standard boards (with
and without no-guess) and every custom board played, the chosen board's
three bests with dates, games, wins, win rate and streaks, the Classic 2D
overall figures, an empty state and the not-saving notice, kept live while
open.

## Acceptance criteria
- The main menu's Records entry routes to the screen (replacing its
  placeholder); the results screen's *Records* opens it on that board; with
  no board given it opens on the last board played.
- The picker lists Beginner, Intermediate and Expert, each with and without
  no-guess, then every custom board played, labelled by `boardLabel`; it
  takes default focus.
- The figures panel shows the three bests with dates, games, wins, win rate,
  current and longest streak; the overall panel shows the Classic 2D totals.
- A board with no games shows an empty state; unreadable records show the
  empty state and never block Back; when records are not being saved the
  screen says so once.
- The screen subscribes to the records store's change notification while
  open and unsubscribes when left.
- Back returns through the shell's back stack to the menu or results screen.
- Mouse, keyboard and controller reach every control.
- Node tests cover the view model with a fake store; Playwright checks the
  routes and the picker.
