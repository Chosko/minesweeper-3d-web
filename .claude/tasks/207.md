# Task 207 — 3D presets without First box 1 and 2; Learn 3D's win offers Cube Intro

Target: claude

## Goal
For feature `3d-play-flow`, drop the First box presets so the 3D presets are
Cube Intro, Cube Beginner, Cube Intermediate and Cube Expert in one group,
and make the Learn 3D end card's win offer *Play Cube Intro* in place of
*Play First box 1*. Games already played on the First box sizes stay in the
history as custom boards, by the rule the feature document already applies
to dropped presets.

## Acceptance criteria
- The 3D preset table (`js/mode3d/board-choice.js`) holds the four cube
  presets only, in that order; the current 3D board choice lists Learn 3D,
  then those four with no group label, then Custom; no "First box" text
  remains in the board choice or its markup.
- A remembered 3D choice naming a removed First box preset opens on Cube
  Beginner with no-guess on, as the remembered-choice rule says.
- `js/records/board.js` and the records model label and list only the four
  cube presets, in `3d-play-flow`'s order, each without then with no-guess;
  a game recorded on 4 × 4 × 3 · 4 or 5 × 5 × 3 · 6 is labelled by its size
  and mine count and listed with the custom boards, its bests, history and
  replays intact. The Records 3D board picker shows no First box entry.
- The start spacing that applied only to the First box presets goes; every
  3D board starts at the camera's ordinary spacing in the three-quarter
  spawn view.
- The Learn 3D end card, on a win, reads "You cleared the box!" with the
  line "Ready for a real board? Cube Intro is a 6 × 6 × 6 box with 10
  mines, a timer and records." and offers *Play Cube Intro* (Enter) and
  *Back to board choice*; *Play Cube Intro* picks Cube Intro with the
  presets' no-guess switch as remembered and saves it as the last choice,
  as *Play First box 1* did. The loss card is unchanged.
- Learn 3D keeps its own fixed 4 × 4 × 3 lesson box and its mine count;
  `js/mode3d/learn.js` no longer describes it as First box 1's.
- `js/records/typical-bbbv.js` drops the First box entries from the
  presets' curve.
- Tests (`tests/mode3d-board-choice.test.mjs`,
  `tests/records-board-3d.test.mjs`, `tests/records-model-3d.test.mjs`,
  `tests/records-screen-3d.test.mjs`, `tests/mode3d-learn.test.mjs`,
  `tests/camera-spawn.test.mjs`, `tests/shell-menu.test.mjs`) are updated
  first to assert the four presets, the First box sizes as custom boards,
  the fallback of a remembered First box choice and the new end card; the
  full suite passes.

## Decisions
- **Owner decision** (DESIGN-CHANGES §2.4): the First box presets are
  removed; Learn 3D's win offers Cube Intro. The board choice's layout
  (one group, no label) is task 167's; this task changes the preset table
  and the end card's action and copy in the current screens.
- `dev/measure-first-box-3d.mjs` stays: it still measures Cube Beginner's
  mine count; only its First box case is dropped.
- 2026-10-19: Skipped — the First box removal and the Cube Intro end card
  moved from `3d-play-flow`, a shipped m2-3d-joins feature, to feature
  `shared-screen-layout` (m2b-themes), since an earlier milestone's feature
  cannot take later work; task 212 replaces this task there with the same
  goal.
