# Task 58 — No-guess cell-count limit for 3D boards

Target: claude

## Goal
Settle the open question of feature `3d-play-flow`: measure no-guess
generation time on 3D boards and set the no-guess cell-count limit so a
board at the limit answers within the generator's attempt budget.

## Acceptance criteria
- A measurement script times no-guess generation on box boards of growing
  cell count and typical densities, and reports where the attempt budget
  stops being met.
- The board choice's no-guess limit constant holds the measured value; the
  disabled switch's message names it.
- `.claude/domain/features/3d-play-flow.md` records the limit and how it was
  measured in place of its open question. Nothing else in the document
  changes.
- A Node test asserts that a board at the limit generates within the
  attempt budget.

## Decisions
- Settled here: the feature document's open question on the no-guess
  cell-count limit, by measurement. `.claude/domain/features/3d-play-flow.md`
  is normally `/architect`'s; this task updates it for exactly this and for
  nothing else.
