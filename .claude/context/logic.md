# Logic — 3D rules (pointer)

The 3D game has no engine of its own: it plays on the shared cell-graph rules
engine, with the box graph provider, the 3D rule profile and the 3D state
view the renderer, picking and HUD read. Read [engine.md](engine.md) and
[engine-rules.md](engine-rules.md) for the rules, [engine-3d.md](engine-3d.md) for what the 3D mode adds, and
[mode3d-session.md](mode3d-session.md) (`create3DGame`, the 3D session) for
how the 3D game is built and driven.

This file stays so that links into the navigation layer from the domain
documents resolve; it holds no content of its own.
